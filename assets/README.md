# assets/

ไฟล์ **ต้นฉบับ** งานอาร์ตและเสียง (.aseprite, .psd, .tmx, .wav ฯลฯ)

ไฟล์ที่ export แล้วสำหรับใช้ในเกมให้วางที่ `apps/client/public/assets/`

| โฟลเดอร์ | เนื้อหา |
|---|---|
| characters/ | ตัวละครผู้เล่น |
| enemies/ | ศัตรู/บอส |
| tilesets/ | tileset สำหรับแมพ |
| maps/ | ไฟล์แมพ Tiled |
| ui/ | ไอคอน, กรอบ, ปุ่ม |
| vfx/ | เอฟเฟกต์สกิล |
| audio/ | เพลง, เสียงประกอบ |
