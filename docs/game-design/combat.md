# ระบบต่อสู้ (Turn-based)

> ยกมาจากเกมเดิมของเจ้าของ **LineRanger_TurnBased** (`src/play/battle.ts`, `ai.ts`, `lib/skills.ts`, `roleTraits.ts`, `formation.ts`, `passives.ts`)
> โค้ด: `packages/combat` (TypeScript ล้วน seed RNG ไม่มี Phaser/DOM — รันบนเซิร์ฟเวอร์ได้) · เทส: `npm test -w @mythoria/combat`
> ในเกม: `scenes/BattleScene.ts` (แผนที่ต่อสู้ของด่าน `world/arenaMap.ts`) + `world/BattleStage.ts` + `ui/battleHud.ts` — ADR 0013

## กติกา (เหมือน LineRanger_TurnBased ทุกข้อ)
- **5 ต่อ 5** — แถวหน้า 2 ช่อง แถวหลัง 3 ช่อง
  - แถวหน้า: DEF ×1.3, HP ×1.15 · แถวหลัง: ATK ×1.15, คริ +8
  - จัดทีมอัตโนมัติ: แทงค์/นักรบไปแถวหน้า ที่เหลือแถวหลัง (หน้าทีม เลือกฮีโร่ 5 ตัว)
- **ลำดับเทิร์นแบบ Honkai: Star Rail**: AV = 10000 / Speed ค่าต่ำสุดได้เล่นก่อน · ความเร็วเปลี่ยนมีผลทันที · ดึงเทิร์น X% (ใช้กับตัวเองไม่ได้)
- **พลังงานทีม** (แชร์ทั้งทีม): เริ่ม 3 (มีซัพพอร์ต +1) สูงสุด 10 · ตีปกติ +1 · สกิลใช้ตาม Cost
  - มอนสเตอร์ไม่ใช้พลังงาน: สกิลวนมาทุก n เทิร์นของตัวเอง (`every` ใน `monsters.ts`)
- **อัลติเมต** (เพิ่มในเกมนี้ ไม่มีในเกมเดิม — ADR 0016, ตัวเลขร่างแรกใน `ULT`):
  - ฮีโร่แต่ละตัวชาร์จ 0–100% แบบ Honkai: Star Rail: ตีปกติ +20 · สกิล/เรียกทีมพิเศษ +30 · โดนตี +10 ต่อครั้ง · ล้มศัตรู +10
  - เต็มแล้วใช้ได้ในเทิร์นของตัวเอง ฟรี ไม่จบเทิร์น ใช้แล้วเหลือ 5%
  - มอนสเตอร์ไม่มี
- **ตีปกติ**: เดี่ยว แถวหน้าก่อน 100% ATK · หลบได้ด้วยหลบการโจมตีปกติ
- **แถวหน้าบัง**: แถวหน้ายังเหลือ → ตีแถวหลังไม่ได้ (นักฆ่าตีข้ามได้)
- **สกิล**: เป้า (เดี่ยว/แถว/ทั้งหมด/ตัวเอง/เพื่อน) + รายการผล · หลบได้ด้วยหลบสกิล · ดีบัฟต้านได้ด้วย **ต้านสถานะ** (เพดาน 70%)
  - มึนงง/ห้ามสกิลจากสกิลทั้งแถว ติดยากขึ้น ×0.7 · ทั้งหมด ×0.5 · หายมึนแล้วติดซ้ำไม่ได้ 1 เทิร์น
- **ดาเมจ** = ATK × % × (1 − DEF/(DEF+800)) × ธาตุ (×1.5/×0.5 ตามธาตุของเป้า) × คริ × อาชีพ × สุ่ม 0.85–1.15 × 1.7
  - เพดานต่อครั้ง 50% ของเลือดสูงสุดเป้า · เลยเทิร์น 48 แรงขึ้น 6%/เทิร์น · ครบ 80 เทิร์นตัดสินที่เลือดเหลือ
- ดาเมจต่อเนื่อง (พิษ/ไฟไหม้/เลือดไหล) ต้นเทิร์น · บาเรียกันทุกอย่างยกเว้นสกิลทะลุอมตะ · โล่รับแทนเลือด · ยั่วยุบังคับตีปกติ · ดูดเลือด · ล้างผลด้านลบ ฯลฯ — ครบตามเกมเดิม
- **ความสามารถอาชีพ** (ตาราง CLASSES): แทงค์รับดาเมจ −15% / นักรบยิ่งเลือดน้อยยิ่งแรง / นักฆ่าตีข้ามแถว / นักยิงตีเป้าเลือดเกินครึ่ง +35% / นักเวทสกิล +20% / ซัพพอร์ตฮีลโล่ +25% และพลังงาน +1
- **AI** (ออโต้ + มอนสเตอร์): ให้คะแนนทุกท่า×เป้า แล้วลองเล่นล่วงหน้าในสำเนา 3 ทาง × 5 เทิร์น — ตัวเดียวกับเกมเดิม
- สุ่มด้วย seed: เริ่มเหมือนกัน = ผลเหมือนกัน (เทสได้ รีเพลย์ได้ ย้ายไปตัดสินที่เซิร์ฟเวอร์ได้)

## ค่าสถานะของเรา → ระบบต่อสู้
| ของเรา | ในระบบต่อสู้ |
|---|---|
| หลบการโจมตีปกติ / หลบการโจมตีสกิล | Evade / Skill Evade (เพดาน 60%) |
| ต้านการโจมตีสกิล | ลดดาเมจจากสกิล % (เพดาน 60%) |
| ต้านการโจมตีปกติ | ลดดาเมจจากตีปกติ % (เพดาน 60%) — เพิ่มใหม่ให้คู่กับต้านสกิล |
| ต้านสถานะ | โอกาสต้านดีบัฟ (เพดาน 70%) |
| — | ความแม่นยำ (Hit / Skill Hit) ยังไม่มีในเกมเรา = 0 |

## ในเกม
- เดินไปหามอนสเตอร์ → การ์ดมอนสเตอร์ → **ต่อสู้** → กล้องพุ่งเข้า จางดำ → **แผนที่ต่อสู้ของด่าน** (ลานในป่า ศาลเจ้าเก่า ไฟวิญญาณ) ฮีโร่ซ้าย มอนสเตอร์ขวา
- กลุ่มที่เจอ (ร่างแรก): มอนสเตอร์ธรรมดามา 3 ตัว · มินิบอสมากับลูกน้อง 2 ตัว (`encounterOf` ใน `monsters.ts`)
- หน้าจอ (แบบ LineRanger_TurnBased): TURN n/80 · เลือดรวมทีมเรา/ศัตรู + VS · ลำดับเทิร์นเป็นข้าวหลามตัดด้านซ้าย (ตัวถัดไปอยู่ล่างสุด) · AUTO / ×1-×2 / ⚙ (หนี) ด้านขวา · เหนือตัว: ธาตุ แถบเลือด(+โล่) เลเวล สถานะ · วงแหวนทองใต้ตัวที่ถึงตา · แถบล่าง: การ์ดตัวที่ถึงตา, ชื่อ ธาตุ อาชีพ เลือด, ท่า 3 ช่อง (ไอคอน ชื่อ เป้า พลังงาน), พลังงานทีม 10 ช่อง
- เทิร์นของฮีโร่: เลือกท่า (Z/X/C หรือ 1/2/3) → แตะเป้า (ชี้เป้าจะเห็นเลือดที่จะหาย) · กดท่าเดิมซ้ำ หรือ Space = ใส่เป้าที่ดีที่สุด · A = ออโต้
- ชนะ → มอนสเตอร์ตัวนั้นหายไปจนครบเวลาเกิดใหม่ (`respawn` ใน `MAP_SPAWNS`) · แพ้/หนี → กลับแผนที่ที่เดิม (ยังไม่มีบทลงโทษ)
