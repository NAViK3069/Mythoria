# Game Design Document (GDD)

> ผู้สร้างจะกำหนดรายละเอียดภายหลัง — แต่ละหัวข้อจะแยกเป็นไฟล์

| ไฟล์ (จะสร้าง) | หัวข้อ |
|---|---|
| `world-and-story.md` | โลก, ภูมิภาค, เนื้อเรื่องหลัก |
| [`characters.md`](characters.md) ✅ | มาสเตอร์/ลูกทีม, โมเดลตัวละคร, มือลอย |
| `combat.md` | กติกาการต่อสู้, turn order, สกิล, สถานะ |
| `exploration.md` | การเดินแมพ, encounter, สมบัติ, ปริศนา |
| `progression.md` | เลเวล, อุปกรณ์, การอัปเกรด |
| `online-modes.md` | PvP, กิลด์, Boss Raid |
| `economy.md` | สกุลเงิน, ร้านค้า, gacha/แพ็กเกจ |
| `art-style.md` | สไตล์ภาพ Pixel 2.5D, ขนาด sprite, พาเลต, มุมกล้อง |
