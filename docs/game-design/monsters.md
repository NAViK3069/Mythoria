# มอนสเตอร์

> ข้อมูลอยู่ที่ `packages/game-data/src/monsters.ts` (`MONSTERS`, `MAP_SPAWNS`) — ระบบต่อสู้จะใช้ชุดเดียวกัน
> ภาพ: `assets/monsters/` (PixelLab) → `python tools/monster_parts.py` → atlas `monsters`; ในแมพ: `apps/client/src/world/Monsters.ts`
> **มอนสเตอร์ทุ่งหญ้า 5 ชนิด + มินิบอสประจำชนิด เป็นร่างแรกที่ Claude ออกแบบตามคำขอ — เจ้าของเกมแก้ชื่อ หน้าตา ธาตุ สกิล และตัวเลขได้ทั้งหมด**

## ทุ่งหญ้า (Lv.1) — 5 ชนิด ชนิดละ 1 ธาตุ
| ชนิด | ธาตุ | Lv | อยู่ที่ไหน | เคลื่อนที่ | มินิบอส (Lv) |
|---|---|---|---|---|---|
| **สไลม์น้ำ** ×7 | น้ำ | 1 | ริมบ่อน้ำ | กระโดดเด้ง | **ราชาสไลม์** (5) — สไลม์ตัวโตสวมมงกุฎ |
| **กระต่ายเขาเดียว** ×6 | แสง | 2 | ทุ่งหญ้าโล่ง | กระโดด (เร็ว) | **หัวหน้าฝูงเขาทอง** (6) — กระต่ายเขาทองตัวใหญ่ แผลเป็นที่ตา ผ้าพันคอแดง |
| **เห็ดพิษ** ×6 | มืด | 2 | แถวดงเห็ด ตอไม้ ขอนไม้ | เดิน | **ราชันเห็ดพิษ** (7) — หมวกม่วงใหญ่จุดเรืองแสง |
| **ต้นกล้าเดินได้** ×5 | ไม้ | 3 | ระหว่างต้นไม้ | เดิน | **พฤกษาเฒ่า** (8) — ต้นไม้เฒ่าเคราตะไคร่ ตาเรืองเขียว |
| **ผึ้งป่า** ×6 | ไฟ | 3 | รอบดงดอกไม้ | บิน | **ราชินีผึ้ง** (9) — ผึ้งตัวโตสวมมงกุฎ เหล็กในเรืองแสง |

- มินิบอสมีถิ่นของตัวเอง (ไกลจากทางแยกกลางแมพที่สุดเท่าที่ถิ่นแบบนั้นมี และห่างกัน) เดินวนแคบๆ ช้ากว่า มีวงแสงสีธาตุใต้ตัว ป้าย "มินิบอส" บนหัวเห็นตลอด
- มอนสเตอร์ไม่เกิดใกล้ทางแยกที่มาถึง ค่ายนักผจญภัย หมู่บ้าน และแท่นวาป
- เห็นผู้เล่นในระยะใกล้ → ขึ้น "!" และหันมามอง · เดินไปใกล้ (หรือแตะที่ตัว) → ปุ่ม "แตะเพื่อดูข้อมูล" → การ์ดมอนสเตอร์ (ค่าสถานะ, ตีปกติ, สกิล) → ปุ่ม **ต่อสู้** (`docs/game-design/combat.md`)

## ค่าสถานะ / สกิล
- เขียนแบบเดียวกับฮีโร่ (11 ค่า, สกิลแบบ LineRanger_TurnBased: เป้า + รายการผล)
- มอนสเตอร์ไม่มีพลังงานทีม: สกิลใช้ทุก n เทิร์น (`every`) ระหว่างนั้นตีปกติ
- ตัวธรรมดาเลือด ~1,400–2,600 พลังโจมตี 150–210 (ฮีโร่ Rare Lv.1: เลือด 2,300–5,600 พลังโจมตี 220–450); มินิบอสเลือด 9,000–15,000 มีสกิล 2 อย่าง
- ตัวเลขทั้งหมดอยู่ใน `MONSTERS` ใน `monsters.ts`

- [ ] ชนแล้วเข้าฉากต่อสู้ยังไง (เดินชน / กดปุ่ม), ศัตรูมาเป็นกลุ่มกี่ตัว, มินิบอสมากับลูกน้องไหม
- [ ] ของดรอป / EXP / เวลาเกิดใหม่ (ตอนนี้ร่างแรก: ตัวธรรมดา 30–40 วินาที, มินิบอส 5 นาที — ยังไม่ได้ใช้)
- [ ] มอนสเตอร์มีเผ่าไหม (ตอนนี้มีแค่ธาตุ)

## ระดับ (Rarity)
- มอนสเตอร์มีระดับเหมือนฮีโร่: Rare < Epic < Legend < Mythic (`rarity` ใน `MONSTERS`)
- **ร่างแรก:** มอนสเตอร์ทั่วไปเป็น Rare ส่วนมินิบอสเป็น Epic — เจ้าของเกมกำหนดใหม่ได้
- ระดับแสดงเป็นกรอบรูปตามระดับในหน้าต่อสู้ และเป็นป้ายในการ์ดมอนสเตอร์
