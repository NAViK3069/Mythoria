# NPC (ชาวเมือง)

> **ชื่อและบทพูดทั้งหมดเป็นตัวแทนชั่วคราว** (บอกแค่ว่าทำหน้าที่อะไร) — รอเจ้าของเกมตั้งชื่อจริงและเขียนบทพูด
> แก้ได้ที่ `apps/client/src/world/npcData.ts` (ชื่อ, บทบาท, บทพูดทีละบรรทัด, ปุ่มเปิดหน้าต่าง, จุดยืน)

## หน้าตา
- สร้างแบบเดียวกับตัวละครหลัก: หัว ตัว ขา 2 ข้าง บนเฟรม 32×32 ไม่มีแขน ใช้มือลอยของตัวหลัก
- เริ่มจากร่างเปล่าของตัวหลัก (Hero00) — ทรงผม/หมวกวาดใหม่ด้วย PixelLab แบบ inpaint เฉพาะส่วนผม (หน้าและตำแหน่งตาเหมือนตัวหลักทุกพิกเซล)
- สีตา, ชุด (วาดเป็นตารางพิกเซลบนบล็อกลำตัว แรเงาแบบเดียวกับเสื้อตัวหลัก), สีรองเท้า กำหนดใน `tools/npc_parts.py`
- ต้นฉบับ: `assets/characters/npcs/<look>.png` → `python tools/npc_parts.py --preview out.png` → atlas `npcs`

## การคุย
- เดินเข้าใกล้ → ปุ่ม "ชื่อ / แตะเพื่อคุย" (หรือกด E) · แตะตัว NPC หรือชื่อบนหัว → เดินไปหาแล้วคุยเอง
- กล่องบทสนทนา: หน้า (จากชิ้นส่วนของ NPC เอง) ชื่อ บทบาท ข้อความพิมพ์ทีละตัว — แตะ/E/Enter/Space ต่อ, Esc ออก; จบแล้วมีปุ่มเปิดหน้าต่าง (ถ้ามี) + "ลาก่อน"
- NPC หันมามองเมื่อผู้เล่นเข้าใกล้ ขยับแบบยืนนิ่งเหมือนตัวหลัก (หายใจ หัวเอียง มือลอย) เดินทะลุไม่ได้
