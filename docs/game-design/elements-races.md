## ธาตุ (5 ธาตุ)
| id | ธาตุ | ชนะทาง |
|---|---|---|
| fire | ไฟ | ไม้ |
| wood | ไม้ | น้ำ |
| water | น้ำ | ไฟ |
| light | แสง | มืด |
| dark | มืด | แสง |

- วงจร: **ไฟ → ไม้ → น้ำ → ไฟ** และ **แสง ⇄ มืด** (ต่างฝ่ายต่างชนะทางกัน)
- ธาตุเดียวกัน หรือไม่แพ้ไม่ชนะทางกัน → ดาเมจปกติ
- ชนะทางธาตุ → ตีแรงขึ้น · แพ้ทางธาตุ → ตีเบาลง
- **ฮีโร่หนึ่งตัวมีธาตุเดียว** (เจ้าของเกมกำหนด 2026-11-10 — เดิมคิดไว้ว่าฮีโร่ระดับสูงมีหลายธาตุแบบ Dragon City ยกเลิกแล้ว) — `HeroDef.element`, `matchup(attack, defender)`
- ในหน้าฮีโร่แสดงธาตุเดียวของตัวนั้น

## หน้าฮีโร่ — ตัวกรอง
- กรองตามธาตุ (เลือกได้หลายธาตุ = เป็นธาตุใดธาตุหนึ่งที่เลือก)
- ธาตุและเผ่ากรองร่วมกัน (ต้องตรงทั้งสองอย่าง) · ปุ่ม "ล้างตัวกรอง" · บอกจำนวน "แสดง n / ทั้งหมด"
- มีแผนภาพวงจรธาตุเล็กๆ ใต้ตัวกรอง
