# เลือดถาวรของฮีโร่ (แบบ Honkai: Star Rail)

> กติกามาจากเจ้าของเกม — ตัวเลขทั้งหมดเป็น **ร่างแรกของ Claude** ให้เจ้าของเกมปรับ อยู่ที่ `packages/game-data/src/vitals.ts` (`VITALS`)

## กติกา
- ฮีโร่มี **เลือดจริงที่ติดตัว**: สู้จบเหลือเลือดเท่าไหร่ ก็เหลือเท่านั้นจนกว่าจะฮีล — ในการต่อสู้ (สกิลฮีล) หรือนอกการต่อสู้ด้วย **ยาฟื้นฟู**
- เลือดเก็บเป็น **สัดส่วน** ของเลือดสูงสุด (0–100%) เพราะเลือดสูงสุดในการต่อสู้มีโบนัสแถวหน้า/หลังบวกเพิ่ม
- ฮีโร่ที่ **ล้ม** (เลือด 0) ลงสู้ไม่ได้ จนกว่าจะใช้ **ยาชุบชีวิต** หรือ **รอคูลดาวน์** แล้วฟื้นเอง
- ทีมที่ล้มหมดทุกตัว เริ่มสู้ไม่ได้ (ขึ้นข้อความให้ชุบชีวิตหรือรอ)
- ทีมพิเศษ (สำรอง 2 ตัว) ที่ล้มอยู่ก็ถูกเรียกมาช่วยไม่ได้

## ตัวเลข (ร่างแรก)
| | ค่า |
|---|---|
| ฟื้นเองหลังล้ม | 30 นาที → ฟื้นด้วยเลือด 30% |
| ยาฟื้นฟู (`potion`) | ฮีลฮีโร่ 1 ตัว 40% ของเลือดสูงสุด (ใช้กับตัวที่ล้มไม่ได้) |
| ยาชุบชีวิต (`revive`) | ชุบตัวที่ล้มด้วยเลือด 50% |
| เริ่มเกมใหม่ | ยาฟื้นฟู 3, ยาชุบชีวิต 1 (เซฟเก่าได้ยาชุบชีวิต 1) |

## บนจอ
- **แถบทีมบนแมพ** (`ui/party.ts`): ฮีโร่ 5 ตัวในทีม ใต้กล่องเควสด้านซ้าย — หน้า ไอคอนธาตุหน้าชื่อ ชื่อ % เลือด แถบเลือดเรียวมีขอบทอง ขีดแบ่ง และแถบจางตามเมื่อเลือดลด (เขียว / เหลือง < 60% / แดงกระพริบ < 30%); ตัวที่ล้มเป็นสีเทา + เวลาที่จะฟื้น
- แตะฮีโร่ → เมนูเล็ก: ยาฟื้นฟู (หรือยาชุบชีวิตถ้าล้ม) พร้อมจำนวนที่มี + ปุ่มจัดทีม
- มือถือแนวตั้ง: เป็นคอลัมน์หน้าฮีโร่ (ธาตุที่มุมล่างซ้ายของกรอบ) + แถบเลือด เรียงลงมาด้านซ้ายใต้แชท (ไม่ไว้เหนือแถบล่าง เพราะบังปุ่มพูดคุย/สู้/วาป); ตัวที่ล้มแสดงแค่เวลา

## ยังไม่ได้ทำ (รอเจ้าของเกม)
- ฟื้นเลือดที่จุดพัก/โรงเตี๊ยมในเมือง, ร้านขายยาชุบชีวิต, ใช้เพชรเร่งคูลดาวน์ — ถ้าต้องการ

## หัวหน้าทีม (กติกาของเจ้าของเกม)
- ทุกทีมที่มีฮีโร่ลงสนามมีหัวหน้าทีม 1 ตัว (เลือกในหน้าจัดทีม มีมงกุฎ)
- หัวหน้าทีมไม่มีวันล้มค้าง: ถ้าล้ม (เลือดหมดหลังจบการต่อสู้) จะฟื้นทันทีด้วยเลือด 15% (`VITALS.leaderRevivePct`) ไม่ต้องรอ 30 นาทีหรือใช้ยาชุบชีวิต
- หัวหน้าทีมเดินตามตัวละครหลักในแผนที่
