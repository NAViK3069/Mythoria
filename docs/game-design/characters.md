# ตัวละคร

## บทบาท
| บทบาท | หน้าที่ |
|---|---|
| **มาสเตอร์ (Master)** | ตัวแทนผู้เล่น เดินสำรวจแมพ — **ไม่ลงสนามต่อสู้** |
| **ลูกทีม (ฮีโร่)** | ตัวละครที่ลงสู้ในสนาม turn-based (กติกาอิงจาก LineRanger_TurnBased) |

## โมเดลตัวละคร (เหมือน ProjectZ)
- ประกอบจาก **4 ชิ้น**: หัว, ตัว, ขาซ้าย, ขาขวา — แต่ละชิ้นวาดบนเฟรม **32×32 px** เดียวกัน เท้าอยู่ที่จุด (16, 32)
- **ไม่มีแขน** — ใช้ **มือลอย** (วาดแยก) เพื่อให้ทำอนิเมชันถือ/แกว่งอาวุธได้ง่าย
- หันได้ **ซ้าย/ขวา** เท่านั้น (กลับด้านภาพ) — **ไม่มีท่าหันหลัง**
- อนิเมชันใช้วิธีเลื่อนชิ้นส่วนทีละ 1–2 พิกเซล (ไม่ยืดภาพ) ภาพจึงคมตลอด
  - เดิน: 8 เฟรม (16 fps), ตัว/หัวกระเพื่อม, เท้าก้าวสลับ, มือแกว่งสวนขา, ฝุ่นตอนเท้าแตะพื้น
  - ยืนนิ่ง: หัวขยับหายใจ, มือลอยขึ้นลงเบาๆ
- โค้ด: `apps/client/src/world/rig.ts`, `apps/client/src/world/MasterCharacter.ts`, มือ `apps/client/src/art/hands.ts`
