# ตัวละคร

## บทบาท
| บทบาท | หน้าที่ |
|---|---|
| **มาสเตอร์ (Master)** | ตัวแทนผู้เล่น เดินสำรวจแมพ — **ไม่ลงสนามต่อสู้** |
| **ลูกทีม (ฮีโร่)** | ตัวละครที่ลงสู้ในสนาม turn-based (กติกาอิงจาก LineRanger_TurnBased) |

## โมเดลตัวละคร (เหมือน ProjectZ)
- ประกอบจาก **4 ชิ้น**: หัว, ตัว, ขาซ้าย, ขาขวา — แต่ละชิ้นวาดบนเฟรม **32×32 px** เดียวกัน เท้าอยู่ที่จุด (16, 32)
- **ไม่มีแขน** — ใช้ **มือลอย 2 ข้าง อยู่ชั้นบนสุดหน้าตัว** เพื่อให้ทำอนิเมชันถือ/แกว่งอาวุธได้ง่าย
- หันได้ **ซ้าย/ขวา** เท่านั้น (พลิกภาพรอบกึ่งกลางตัวทันที) — **ไม่มีท่าหันหลัง**
- ขาห้อยจากสะโพก: ตัวเด้งขึ้นลงเมื่อไหร่ ขาขึ้นตามด้วย ตัวกับขาจึงไม่แยกกัน
- Hitbox อยู่ที่เท้า (วงรี 9×5 px) — ชนเฉพาะ "ฐาน" ของวัตถุ เดินอ้อมหลังยอดไม้/กำแพงได้ และวัตถุที่บังจะจางลง
- อนิเมชัน **ลื่นไหล ไม่ snap ทีละพิกเซล**: ชิ้นส่วนเลื่อนแบบทศนิยม + หมุนเล็กน้อย + สปริง
  - เดิน: รอบก้าวผูกกับระยะทางที่เดินจริง (เท้าไม่ไถล), ตัวกระเพื่อม/เอนไปข้างหน้า, หัวตามหลังตัวนิดๆ และพยักตามก้าว, มือแกว่งสวนขา, ฝุ่นตอนเท้าแตะพื้น
  - หยุด/ออกเดิน: ตัวยุบ-เด้งเล็กน้อย
  - ยืนนิ่ง: หายใจ, หัวเอียงช้าๆ, มือลอยขึ้นลงคนละจังหวะ

## ท่ามือ (`apps/client/src/art/hands.ts`)
| ชื่อ | ใช้เมื่อ |
|---|---|
| `open` | ผ่อนคลาย เดิน/ยืน |
| `fist` | กำหมัด ต่อย ตั้งการ์ด |
| `grip` | กำด้ามดาบ/ไม้เท้า/เครื่องมือ |
| `point` | ชี้ เลือกเป้าหมาย |
| `palm` | แบมือ ร่ายเวท ห้าม ป้องกัน |
| `claw` | งุ้มนิ้ว ชาร์จพลัง คว้า |
| `thumb` | ชูนิ้วโป้ง ชนะ/อีโมต |
| `pinch` | หยิบของเล็ก (ยา เหรียญ การ์ด) |

เปลี่ยนท่าด้วย `master.setHands('grip', 'open')` (มือหน้า, มือหลัง)

- โค้ด: `apps/client/src/world/rig.ts`, `apps/client/src/world/MasterCharacter.ts`
