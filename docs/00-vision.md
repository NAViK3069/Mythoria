# 00 — Vision

## เกมนี้คืออะไร
**Mythoria** คือเกม RPG แฟนตาซีแบบ Turn-based ภาพแนว Pixel 2.5D ที่เล่นบนเว็บเบราว์เซอร์ได้ทุกอุปกรณ์

## เสาหลัก (Pillars)
1. **สำรวจโลก** — เดินสำรวจแมพแบบ free-roam เจอศัตรู/NPC/สมบัติบนแมพ (อ้างอิงความรู้สึก: AFK Journey)
2. **ต่อสู้ Turn-based ที่มีชั้นเชิง** — ลำดับเทิร์นตามค่า Speed, สกิล/อัลติ, จุดอ่อนธาตุ (อ้างอิงความรู้สึก: Honkai: Star Rail)
3. **เล่นด้วยกันออนไลน์** — กิลด์, PvP, Boss Raid, เนื้อเรื่องต่อเนื่อง
4. **เข้าถึงง่าย** — เปิดลิงก์แล้วเล่นได้ทันที มือถือ / PC / iPad, ทัชสกรีน + เมาส์ + คีย์บอร์ด

## แพลตฟอร์มเป้าหมาย
- เว็บเบราว์เซอร์ (Chrome, Safari, Edge, Firefox) บน Desktop / Mobile / Tablet
- ติดตั้งเป็น PWA (Add to Home Screen) ได้ แต่ **ไม่ใช่แอปใน Store**

## สิ่งที่ยังรอกำหนด (ผู้สร้างจะกำหนดภายหลัง)
- [ ] ชื่อโลก, เนื้อเรื่องหลัก, ตัวละครหลัก
- [ ] มุมกล้อง/สไตล์ภาพ 2.5D ที่แน่นอน (Isometric / Top-down เอียง / HD-2D)
- [ ] ระบบต่อสู้โดยละเอียด (จำนวนตัวในทีม, ทรัพยากรสกิล, ธาตุ)
- [ ] ระบบได้ตัวละคร (Gacha / Story / อื่นๆ) และโมเดลรายได้
