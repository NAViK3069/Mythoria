# 03 — Roadmap: จากศูนย์ถึงเปิดให้บริการ

> ค่อยเป็นค่อยไป — จบแต่ละ Phase ต้องมีผลลัพธ์ที่ **เล่นได้/ทดสอบได้** เสมอ

## Phase 0 — Foundation (ตอนนี้)
- [x] สร้าง repo + โครงโฟลเดอร์ + เอกสารแผน
- [ ] ผู้สร้างกำหนดคอนเซปต์เกม (โลก, ตัวละคร, สไตล์ภาพ, ระบบต่อสู้) → เขียนลง `docs/game-design/`
- [ ] ตัดสินใจมุมกล้อง 2.5D + engine (Phaser vs Three.js) → บันทึก ADR

## Phase 1 — Prototype (เล่นได้บน GitHub Pages)
เป้าหมาย: พิสูจน์ว่า "เดินแมพ → เจอศัตรู → สู้ turn-based" สนุกและลื่นบนทุกอุปกรณ์
- [x] ตั้ง Vite + Phaser + TypeScript ใน `apps/client`
- [x] GitHub Actions deploy ขึ้น GitHub Pages อัตโนมัติ (ต้องเปิด Pages ใน Settings ก่อน)
- [x] ตัวละครมาสเตอร์ (หัว/ตัว/ขา + มือลอย) เดินได้ หันซ้าย/ขวา (joystick บนจอ / คลิก / WASD), กล้องตาม, depth sorting
- [x] แมพทุ่งหญ้าแรก: tileset จาก PixelLab (autotile), บ่อน้ำ, ทางดิน, ซากศาลเจ้า, ป่ารอบขอบ, ชนน้ำ/ต้นไม้/กำแพงได้
- [x] แสงและบรรยากาศ: เงาทอด, เงาเมฆ, god rays, ประกายน้ำ, ละออง, ไฟกระถาง, เอฟเฟกต์ pixelfx
- [x] ตัวละครขยับลื่น (สปริง) + มือลอย 8 ท่า
- [ ] เครื่องมือวาง/แก้แมพ (ตอนนี้แมพสร้างจากโค้ด `meadowMap.ts`)
- [x] UI เกมชุดแรก: HUD + หน้าต่างโปรไฟล์ ตั้งค่า ประกาศ จดหมาย ร้านค้า กระเป๋า ทีม ฮีโร่ ซัมม่อน เพื่อน อีเวนต์ เควส กิลด์ โหมดเล่น แชท (ข้อมูลตัวอย่างในเครื่อง)
- [x] UI รอบ 2: มินิแมพ + หน้าแผนที่, ป๊อปอัปรับรางวัล, ป้ายชื่อพื้นที่, เงินนับขึ้น, key art โหมดเล่น/ซัมม่อน (PixelLab)
- [x] เอฟเฟกต์ของเราเอง (ผีเสื้อ 7 ชนิด, กองไฟ, คบเพลิง, ไฟวิญญาณ) + แมพใหญ่ขึ้น 128×92: หมู่บ้านร้าง, ค่ายพักแรม, หิ่งห้อย, ใบไม้ร่วง
- [x] จุดวาป 4 แท่น + เอฟเฟกต์วาปออก/วาปเข้า + หน้าต่างเลือกจุดหมาย
- [x] เมืองหลัก (ล็อบบี้) พร้อมน้ำพุ VFX, ร้านค้า/กิลด์/วิหาร/กระดานเควสเปิดหน้าต่างได้, เดินทางข้ามแผนที่ (เมือง ↔ ทุ่งหญ้า Lv.1)
- [x] ระบบฮีโร่ชุดแรก: 6 อาชีพ, 4 ระดับ, 11 ค่าสถานะ, 4 ช่องอุปกรณ์, ดาว C0–C5; ฮีโร่ Rare เริ่มต้น 7 ตัว (ร่างแรก) พร้อมหน้าตา/อาวุธ; หน้ารายชื่อ (กรอง อาชีพ/ระดับ/ธาตุ/เผ่า) + หน้าฮีโร่
- [x] ธาตุ 5 ธาตุ + เผ่า 10 เผ่า: ข้อมูลใน `packages/game-data`, ไอคอน, ตัวกรองในหน้าฮีโร่ (ตัวคูณดาเมจ/คอมโบเผ่ารอกำหนด)
- [x] NPC 14 คนในเมือง/ทุ่งหญ้า สร้างจากชิ้นส่วนตัวหลัก (ทรงผม/หมวก/ชุด/สีตาต่างกัน) มีชื่อบนหัว คุยได้ เปิดร้าน/กิลด์/ซัมม่อน/เควส — ชื่อ/บทพูดยังเป็นตัวแทน
- [x] สัตว์ในแผนที่ประกอบจากชิ้นส่วน: แมว 5 สี (เดิน ยืน นั่ง นอน), กระรอก (กระโดด นั่งแทะ หนีขึ้นต้นไม้), นกกระจอกเป็นฝูง (กระโดด จิก บินหนี)
- [x] มอนสเตอร์ในทุ่งหญ้า 5 ชนิด + มินิบอสประจำชนิด (ร่างแรก): เดิน/กระโดด/บินตามถิ่น, ป้ายชื่อ, การ์ดข้อมูล
- [x] Encounter: เจอมอนสเตอร์บนแมพ → การ์ด → ต่อสู้ตรงจุดนั้น (กล้องซูมเข้า) → ชนะแล้วมอนสเตอร์หายจนเกิดใหม่
- [x] `packages/combat`: ยกระบบจาก LineRanger_TurnBased ทั้งหมด (AV ตาม Speed, พลังงานทีม, สกิล/สถานะ, AI) + unit test (vitest)
- [x] Battle (บนแมพ): ฮีโร่ถืออาวุธ vs มอนสเตอร์, เลือกท่า/เป้า + พรีวิว, ออโต้/×2/หนี, ตัวเลขดาเมจ, หน้าผล · หน้าทีมเลือก 5 ตัว
- [x] หน้าต่อสู้แบบพิกเซลทั้งหมด (กรอบจาก PixelLab) + VFX ของเรา: แถบเลือดบนสนาม, ตัวเลขดาเมจ, คริ, คอมโบ, "!", เสาแสง VICTORY (ADR 0014)
- [x] ทีม 7 ตัว: ทีมหลัก 5 + ทีมพิเศษ 2 (เรียกลงมาร่ายสกิล 1 แล้วติดคูลดาวน์) พร้อมแถบล่างแบบใหม่ตาม wireframe ของเจ้าของเกม
- [ ] รางวัลหลังต่อสู้, พาสซีฟ/พรสวรรค์ของฮีโร่ในการต่อสู้
- [ ] Responsive: แนวนอน/แนวตั้ง, iPad, เต็มจอบนมือถือ
- [x] เซฟลง localStorage: ข้อมูลผู้เล่น + ตำแหน่ง (แมพ จุด ทิศ) — รีเฟรช/ปิดแล้วกลับมาที่เดิม, แมพหาย/จุดเดินไม่ได้ → กลับเมือง (ADR 0017)

## Phase 2 — Vertical Slice (เกมเล็กที่ครบวงจร)
- [ ] ล็อกสไตล์ภาพ: ตัวละคร, tileset, UI, VFX ชุดแรก
- [ ] ภูมิภาคแรก + เนื้อเรื่องบทที่ 1 (ระบบบทสนทนา/เควสต์)
- [ ] ตัวละคร 6–8 ตัว, จุดอ่อนธาตุ, เลเวล/อุปกรณ์/อัปสกิล
- [ ] เมนูหลัก: ทีม, กระเป๋า, ตัวละคร, ตั้งค่า
- [ ] เสียง/เพลง, PWA ติดตั้งได้
- [ ] ให้คนอื่นทดลองเล่นผ่าน GitHub Pages + เก็บ feedback

## Phase 3 — Backend & Accounts (เริ่มออนไลน์)
- [ ] `apps/server`: Fastify + Colyseus + PostgreSQL + Redis (dev ด้วย Docker Compose ใน `infra/`)
- [ ] ระบบบัญชี: Guest → ผูก Email/Google, cloud save
- [ ] ย้ายการตัดสินผลต่อสู้/รางวัลไปที่ server (server-authoritative)
- [ ] `OnlineGameService` ใน client
- [ ] Deploy staging: client (Cloudflare Pages/Vercel) + server (Fly.io/Railway) + โดเมน

## Phase 4 — Online Features
- [ ] เพื่อน, แชท
- [ ] กิลด์: สร้าง/เข้าร่วม/ยศ/แชทกิลด์/ภารกิจ
- [ ] PvP Async Arena + อันดับ (season)
- [ ] World Boss Raid + กระดานคะแนน
- [ ] (ต่อยอด) Realtime PvP / Co-op Raid
- [ ] ระบบ mail / event / daily mission

## Phase 5 — Closed Beta
- [ ] Admin panel (`apps/admin`): ดูผู้เล่น, ส่งของ, แบน, จัดอีเวนต์
- [ ] Analytics / telemetry, error tracking (Sentry)
- [ ] Load test, anti-cheat, rate limit, backup DB
- [ ] Terms of Service, Privacy Policy (**PDPA**), นโยบายผู้เยาว์
- [ ] ปรับสมดุลเกมจากข้อมูลจริง

## Phase 6 — Monetization & Payment
- [ ] ออกแบบเศรษฐกิจ: สกุลเงินพรีเมียม, แพ็กเกจ, Battle Pass / Monthly card
- [ ] เชื่อม Payment Gateway (Stripe และ/หรือ Opn/Omise) — บัตร, PromptPay, TrueMoney
- [ ] Flow: client ขอ checkout → server สร้าง order → ผู้เล่นจ่าย → **webhook ยืนยัน** → server เติมของ (idempotent)
- [ ] Ledger ธุรกรรม, ประวัติการซื้อ, ใบเสร็จ, นโยบายคืนเงิน
- [ ] ถ้ามี Gacha: **เปิดเผยอัตราดรอป**, ระบบ pity, ตรวจข้อกฎหมาย
- [ ] ทดสอบด้วย test mode ทุกช่องทางก่อนเปิดจริง
- [ ] จดทะเบียนธุรกิจ/ภาษี ตามที่ผู้ให้บริการชำระเงินกำหนด

## Phase 7 — Official Launch & Live Ops
- [ ] Production infra: CDN, หลายเครื่อง, monitoring/alert, autoscale
- [ ] Open Beta → Official Launch
- [ ] รอบอัปเดตเนื้อหา, อีเวนต์ตามฤดูกาล, ชุมชน (Discord/Facebook)
