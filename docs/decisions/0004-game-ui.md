# 0004 — UI เกม (HUD + หน้าต่าง)

- สถานะ: Accepted
- วันที่: 2026-11-08

## บริบท
ต้องมี UI ครบชุดแบบเกมมือถือ/เว็บ: โปรไฟล์ ตั้งค่า ประกาศ จดหมาย ร้านค้า กระเป๋า ทีม ฮีโร่ ซัมม่อน เพื่อน อีเวนต์ เควส กิลด์ โหมดเล่น แชท และเงิน/เพชร/พลังงาน — ดูเท่ อ่านง่าย ใช้ได้ทั้ง PC มือถือ iPad

## การตัดสินใจ
- **HTML/CSS ทับบน canvas** (`apps/client/src/ui/`) — ตัวหนังสือไทยคมทุกจอ จัด layout ตามขนาดจอได้ง่าย ไม่ต้องวาด UI ใน Phaser
  - `Hud.ts` แถบบนสุด/ข้าง/ล่าง, `Modal.ts` ระบบหน้าต่าง (เปิดทีละหน้า, Esc/แตะพื้นหลังเพื่อปิด, หยุดการเดินตอนเปิด), `panels/*` เนื้อหาแต่ละหน้า
  - `store.ts` ข้อมูลผู้เล่น (ตอนนี้เก็บใน localStorage เป็นข้อมูลตัวอย่าง — ภายหลังมาจากเซิร์ฟเวอร์ผ่าน GameService)
- **ภาพจาก PixelLab**: ไอคอน 24 ชิ้น (Create Image Pro, ชุดละ 8 แบบ) + กรอบหน้าต่างทอง (Create UI Asset) ใช้เป็น 9-slice; ต้นฉบับอยู่ `assets/ui/`, คัดลอกด้วย `tools/build_ui_assets.py`
- **ฟอนต์ Kanit** (มากับเกม ใช้ออฟไลน์ได้) — ตัวเลขใช้ Kanit ด้วย เพราะฟอนต์พิกเซลทำให้ 5 กับ S สับสน
- **โทน**: กระจกสีเขียวอมฟ้าเข้ม + กรอบทองตัดมุมแบบพิกเซล + ปุ่มเรืองแสง (ซัมม่อนม่วง, โหมดเล่นเขียวฟ้ามีแสงวิ่ง)
- ระบบที่ต้องมีเซิร์ฟเวอร์ (เพื่อน กิลด์ แชทออนไลน์ ชำระเงิน) แสดงหน้าตาครบแต่บอกว่าจะเปิดในเฟสออนไลน์; ฮีโร่/ซัมม่อนรอข้อมูลฮีโร่จากผู้สร้าง

- **การควบคุม**: PC ใช้เมาส์คลิก (ซ้ายหรือขวา) เพื่อเดินไป และกดค้างเพื่อเดินตามเคอร์เซอร์แบบเกม MOBA — ไม่มีจอยสติ๊กลากบน PC; มือถือ/แท็บเล็ตยังแตะเพื่อเดินและลากเป็นจอยสติ๊กได้
- **เครื่องหมายจุดเดิน** (`world/MoveMarker.ts`): ลูกศรเขียวเรืองแสงตกลงมา กระแทกพื้นแล้วเด้ง วงแหวนแผ่ออก 2 ชั้น มีประกายกระเด็น

### อัปเกรด UI รอบ 2 (2026-11-08)
- **HUD**: โปรไฟล์กรอบทองมีอัญมณีที่มุม + ป้ายเลเวลหกเหลี่ยม + แถบ EXP มีแสงวิ่ง; ตัวติดตามเควสมีแถบความคืบหน้า และเรืองแสงเขียวเมื่อพร้อมรับรางวัล; เหรียญ/เพชร/พลังงาน ไอคอนยื่นทับขอบซ้าย ตัวเลขนับขึ้น/ลงพร้อมแสงวาบเมื่อค่าเปลี่ยน; ปุ่มข้าง (อีเวนต์ เควส ร้านค้า ซัมม่อน) จัดเป็นตาราง 2×2 ข้างมินิแมพ; ปุ่มโหมดเล่นเป็นตราวงกลมมีวงแสงหมุน ยื่นออกจากแผ่นทอง; แถบล่างมีอัญมณีกลางกรอบ
- **มินิแมพ** (`world/minimap.ts`): วาดครั้งเดียวตอนโหลด จากพื้นที่อบไว้แล้ว + ภาพย่อของต้นไม้/กำแพง/หิน/พุ่มจริง (1 px = 4 px ในโลก) ใส่ HUD เป็น `<canvas>`; ทุกเฟรมขยับแค่ลูกศรผู้เล่นและกรอบมุมกล้อง (แตะ DOM เฉพาะเมื่อขยับจริง); จุดหมายเควสเรื่องหลักกระพริบจนกว่าจะทำสำเร็จ; แตะมินิแมพเพื่อเปิดหน้าต่าง "แผนที่" ขนาดใหญ่
- **ป้ายชื่อพื้นที่**: ชื่อพื้นที่ตัวใหญ่สีทองขึ้นกลางจอตอนเข้าแมพแล้วจางหาย (ภาษาไทยห้ามใส่ letter-spacing มาก — สระ/วรรณยุกต์จะหลุดจากพยัญชนะ)
- **ป๊อปอัปรับรางวัล** (`ui/reward.ts`): แสงรัศมีหมุน ริบบิ้นทอง ไอเทมเด้งขึ้นทีละชิ้น ประกายกระเด็น — ใช้กับรับเควส จดหมาย ล็อกอิน ซื้อของ เปิดหีบ; แตะ/Esc/Enter เพื่อปิด (Esc ไม่ปิดหน้าต่างข้างใต้ไปด้วย) และตัวละครหยุดเดินระหว่างแสดง
- **หน้าต่าง**: หัวมีตราไอคอนกรอบทอง + ชื่อไล่สีทอง + ลายเส้นประดับ + ปุ่มปิดอัญมณีแดงหมุนเมื่อชี้; แท็บทองมีขอบตัดมุม; ปุ่มแบบนูนกดยุบ; การ์ด/แถวรายการมีแสงวิ่งเมื่อชี้; พื้นหลังเบลอเล็กน้อยเฉพาะเครื่องที่มีเมาส์
- **Key art จาก PixelLab** (`assets/ui/art/`, Create Image Pro 160×90 ชุดละ 4 ภาพ คัด 1 — ใช้ไป 60 generations): สำรวจโลก เนื้อเรื่อง อารีน่า บอสเรด ดันเจี้ยน ซัมม่อน — แสดงแบบ pixelated ขยายเต็มการ์ด; ภาพเป็น **ตัวแทนชั่วคราว** ไม่ได้กำหนดเนื้อเรื่อง/บอส ผู้สร้างเปลี่ยนได้ด้วยการวางไฟล์ชื่อเดิม
- จอเล็ก: ≤760 px กว้าง **หรือ** ≤500 px สูง (มือถือแนวนอน) ใช้ HUD แบบกะทัดรัด; มือถือแนวตั้งเรียงเงินใต้โปรไฟล์ มินิแมพซ้าย ปุ่มข้างขวา; `prefers-reduced-motion` ปิดแอนิเมชันวนซ้ำ

### ปรับตามคำติชม (2026-11-08)
- **กรอบหน้าต่างใหม่** (PixelLab UI panel `mythoria_panel_v2a`, 10 generations): ทองบางลายเถาที่มุม ไม่มีเม็ดอัญมณีแดง/ฟ้า — ตัดขอบแล้วเติมกลางเป็นกระจกเข้ม (`tools/build_ui_assets.py`) ใช้ 9-slice มุม 56 px แสดง 1:1 ให้พิกเซลคม; `.panel` ใช้ `box-sizing: border-box` กรอบจึงไม่ล้นจอ (ทดลองแบบ B ทองหนา+ใบไม้ มุมกลางเป็นหินร้าว ไม่ใช้เพราะยืดแล้วลายเพี้ยน)
- **ปุ่มปิด / ปุ่มบวก**: วาดเครื่องหมายเป็นพิกเซล SVG (`glyph()` ใน `ui/dom.ts`) แทนตัวอักษร ✕ / + ที่ไม่ตรงกลาง; ปุ่มปิดเป็นอัญมณีแดงกรอบทอง ไม่หมุน; ปุ่มบวกเป็นอัญมณีเขียวกรอบทองบาง
- **กรอบโปรไฟล์**: วงทองตัดมุมแปดเหลี่ยมเรียบๆ ไม่มีเม็ดสีที่มุม, เลเวลเป็นเหรียญกลมกรอบทองมุมขวาล่าง (ไม่ถูกตัดขอบ)
- **ป้ายชื่อเหนือหัวตัวละคร**: `Lv.N` + ชื่อ เป็น HTML (ตัวไทยคมทุกซูม) วางตำแหน่งในอีเวนต์ `followupdate` ของกล้อง — หลังกล้องขยับแล้วในเฟรมนั้น ป้ายจึงติดหัวไม่สั่น
- แถวเงินย่อเป็นแบบกะทัดรัดตั้งแต่จอกว้าง ≤1060 px (ก่อนหน้านี้ที่ 800 px จะทับโปรไฟล์)

## ผลที่ตามมา
- เปลี่ยนหน้าตา UI ได้ด้วย CSS อย่างเดียว
- ปุ่ม/หน้าต่างรับการแตะเอง เกมด้านล่างไม่เดินตาม; ช่องพิมพ์ไม่โดนปุ่ม WASD แย่ง
