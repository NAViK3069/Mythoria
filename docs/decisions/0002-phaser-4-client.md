# 0002 — Client ใช้ Phaser 4 + Vite

- สถานะ: Accepted
- วันที่: 2026-11-08

## บริบท
ต้องการเกม pixel art บนเว็บที่ลื่นทั้ง PC/มือถือ/iPad และตัวละครแบบประกอบชิ้นส่วน (หัว/ตัว/ขา + มือลอย) เหมือน ProjectZ

## การตัดสินใจ
- ใช้ **Phaser 4.2.1** (`pixelArt: true`, `roundPixels: true`) กับ **Vite** และ **TypeScript**
- ตัวละครเป็น `Container` ที่มีภาพแต่ละชิ้น เลื่อนทีละพิกเซลเพื่อทำอนิเมชัน แล้วกลับด้านด้วย `scaleX = -1`
- กล้องซูมเป็น **จำนวนเต็ม** (2–4 เท่าตามขนาดจอ) พิกเซลจึงเป็นสี่เหลี่ยมคมเสมอ
- ปุ่มควบคุมรวมเป็นชุดเดียว: คีย์บอร์ด, คลิก/แตะเพื่อเดินไป, ลากเป็นจอยสติ๊ก

## ผลที่ตามมา
- build เป็นไฟล์ static ขึ้น GitHub Pages ได้ทันที (`base: './'`)
- ถ้าต่อไปต้องการฉาก 3D แบบ HD-2D ค่อยพิจารณา Three.js ใหม่
