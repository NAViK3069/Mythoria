# 0019 — มอนสเตอร์สังเกต/ไล่ตาม และการต่อสู้บนแผนที่ (เทิร์นเบสอยู่ข้างใน)

- สถานะ: Accepted (ระยะที่ 1)
- วันที่: 2026-11-14

## บริบท
เจ้าของเกมต้องการ:
- เดินเข้าใกล้มอนสเตอร์ → มีเครื่องหมาย (หมุดมีลูกศรวน ตามภาพสเก็ตช์) และหลอดโหลดวงกลม → เต็มแล้วขึ้น "!" มอนสเตอร์เดินตาม ถ้าถึงตัวเรา = บังคับสู้ (แบบโปเกม่อน)
- สู้บนแผนที่ได้โดยไม่ต้องเข้าหน้าเทิร์นเบส: หัวหน้าทีมเล่นท่าตีมอนสเตอร์ มีหลอดเลือดรวมของทั้ง 2 ฝ่าย ตัวเลขดาเมจ/คริ/MISS/ฮีล แต่ข้างในยังเป็นเทิร์นเบสออโต้; มอนสเตอร์ตายแล้วสลาย; คนอื่นเห็นเราสู้อยู่บนแผนที่
- หนี/ยกเลิกได้ เข้าไปดูหน้าเทิร์นเบสได้ และพับกลับมาดูบนแผนที่ได้
- เตรียมปุ่มฟาร์มออโต้แบบ Ragnarok; 1 ผู้เล่นต่อ 1 มอนสเตอร์ (แย่งกันไม่ได้)
- ให้ Claude คิดเงื่อนไขที่สมเหตุสมผล

## การตัดสินใจ

### 1. การต่อสู้มี "ตัวเดียว" สองหน้าจอ
- การต่อสู้คือ `Battle` ของ `packages/combat` ตัวเดิม (ทีม 5 + ทีมพิเศษ 2 + กลุ่มมอนสเตอร์ตาม `encounterOf`)
- **บนแผนที่ = เทิร์นเบสที่เล่นออโต้** (`planAuto` ตัวเดียวกับปุ่ม AUTO ในหน้าต่อสู้) — `world/FieldFight.ts` เดินเกมทีละท่าทุก `FIELD_FIGHT.step` วินาที
- **หน้าเทิร์นเบส = การต่อสู้เดียวกันที่ผู้เล่นเลือกท่าเอง**
- เพราะเป็นกติกาเดียวกัน **ไม่ต้องล็อกด้วยเลเวลหรือเควส**: สู้บนแผนที่ได้ตลอด ผลที่ได้เท่ากับกด AUTO ในหน้าต่อสู้ ส่วนหน้าเทิร์นเบสมีไว้เมื่ออยากควบคุมเอง (มอนเก่ง/มินิบอส)
- ช่องว่างเลเวลใช้กับ "การสังเกต" แทน (ข้อ 2)

### 2. มอนสเตอร์สังเกตและไล่ตาม (`AGGRO` ใน game-data — ร่างแรก)
- มอนปกติ: เข้าใกล้ในรัศมี 72 px → หมุดเหนือหัว + วงแหวนเติม (ใกล้ยิ่งเร็ว 1–3.2 วินาที) ออกนอกรัศมีแล้วค่อยๆ ลด
- เต็ม → "!" → วิ่งตาม (เร็ว ×1.8 ของตัวเอง ขั้นต่ำ 44 px/s — ช้ากว่าเรา 92 จึงหนีได้) จับได้ (≤14 px) → **บังคับสู้บนแผนที่**
- เลิกตาม: ตามเกิน 7 วินาที / ห่างบ้านเกิน 260 px / ติดสิ่งกีดขวาง → เดินกลับบ้าน **ตามทางที่มา** (ไม่ทะลุกำแพง)
- ไม่สังเกต: มินิบอส (เฝ้ารัง — ผู้เล่นเริ่มเอง ไม่มีการบังคับสู้บอส), มอนที่เลเวลต่ำกว่าเรา ≥10, ระหว่างสู้/วาร์ป/เปิดหน้าต่าง/ทีมล้มหมด, และ 4 วินาทีหลังจบการต่อสู้หรือหนี
- หมุด + วงแหวนวาดเป็นพิกเซลของเราเอง (`world/noticePin.ts`) บนชั้นเอฟเฟกต์ของแผนที่

### 3. หน้าตาการต่อสู้บนแผนที่ (`world/FieldFight.ts`)
- หัวหน้าทีม (ตัวที่เดินตาม) ก้าวออกไปยืนหน้ามอนสเตอร์ ตัวละครหลักถอยไปยืนข้างหลัง
- ใครในทีมเราออกท่า → **หัวหน้าเป็นคนตี** (พุ่งเข้าฟัน) ใครฝั่งมอนออกท่า → มอนพุ่งใส่หัวหน้า
- ตัวเลข: ดาเมจ, CRIT (จอสั่นเล็กน้อย), MISS, IMMUNE, +ฮีล, โล่, DOT, STUN, คำว่า SKILL / ULTIMATE / ASSIST
- หลอดเลือดรวม 1 หลอดต่อฝ่าย (HP รวมของทั้งทีม / ทั้งกลุ่มมอน) เหนือหัวหน้าและเหนือมอน
- ชนะ → มอนสลายเป็นหิน (`Dissolve` ตัวเดียวกับในสนาม) + VICTORY!; แพ้ → DEFEAT (หัวหน้าไม่มีวันล้ม — ADR 0018)
- จบแล้วเลือดที่เหลือของฮีโร่บันทึกถาวร (`setHp`) เหมือนหน้าเทิร์นเบส
- แถบบนด็อก: ชื่อมอน ×จำนวน "ออโต้" [หน้าต่อสู้] [หนี]

### 4. หนี / เปิดหน้าต่อสู้ / 1 ต่อ 1
- **หนี**: หยุดทันที ฮีโร่เก็บเลือดที่เหลือ มอนหมดความสนใจ ไม่มีรางวัล
- **หน้าต่อสู้**: ส่งมอนที่ยังยืนอยู่พร้อมเลือดที่เหลือไปหน้าเทิร์นเบส (`BattleData.foeHp`) ฮีโร่ใช้เลือดที่เหลือ
- การ์ดมอนสเตอร์มี 2 ปุ่ม: "ต่อสู้" (เทิร์นเบส) และ "สู้ในแผนที่ (ออโต้)"
- มอนที่มีคนสู้อยู่ (`Monster.engaged`) ไม่สังเกต/ไม่ไล่ และเลือกสู้ซ้ำไม่ได้ — วันหลังเซิร์ฟเวอร์ถือสิทธิ์นี้
- ชนะครั้งแรกต่อชนิดมอน บันทึกใน `player.beaten` — **เงื่อนไขปลดล็อกฟาร์มออโต้** (แนะนำ: ต้องเคยชนะมอนชนิดนั้นก่อน 1 ครั้ง จะโหมดไหนก็ได้)

## ระยะที่ 2 (2026-11-14, คำขอของเจ้าของเกม)
- **เดินได้ระหว่างสู้บนแผนที่** ถ้าเดินห่างจากจุดสู้เกิน `FIELD_FIGHT.leash` (120 px) = หนี
- **จังหวะ** เท่ากับหน้าเทิร์นเบสที่กด x2 โดยประมาณ: ท่าละ `step` 1.0 วินาที สกิล +0.6 อัลติ +1.3
- **แถบทีมด้านซ้ายแสดงเลือดแบบเรียลไทม์** ระหว่างสู้บนแผนที่ (`showLiveHp` ใน ui/party.ts) และแถบเหนือด็อกมีหลอดเลือดรวมของทั้งสองฝ่าย (เรา VS มอน)
- หลอดเลือดบนแผนที่ไม่ทับชื่อ: ป้ายชื่อมอนซ่อนระหว่างถูกสู้ หลอดอยู่ตรงที่ป้ายเคยอยู่
- **หน้าเทิร์นเบสรับการต่อสู้ที่กำลังเล่นอยู่ "ตัวเดียวกัน"** (`Battle` object เดิม → `BattleStage` รับ `existing`): ไม่มีเดินเข้า/อินโทร เลือด พลังงาน คูลดาวน์ เกจอัลติ บัฟ/ดีบัฟ ตรงตามจริง และเปิด AUTO + x2 ไว้ให้
- **พับกลับมาดูบนแผนที่** (ปุ่ม "ดูบนแผนที่" ในหน้าเทิร์นเบส ทุกการต่อสู้): พับตอนจบเทิร์นที่กำลังเล่น แล้วการต่อสู้เดิมเล่นต่อบนแผนที่
- **ฟาร์มออโต้** (`ui/farm.ts`, `FARM` ใน game-data): ปุ่ม AUTO เหนือด็อกขวา → เลือกชนิดมอนในแมพ (ปลดล็อกเมื่อเคยชนะ — `FARM.needWin`) → ตัวละครเดินไปหามอนที่ใกล้ที่สุดที่ไปถึงได้ สู้บนแผนที่ แล้วไปตัวต่อไป; หยุดเมื่อเดินเอง แตะมอน/NPC หนี เปลี่ยนแมพ หรือทีมเหลือแค่หัวหน้า
- มอนสเตอร์ในทุ่งหญ้าเพิ่มเป็น 2 เท่า (65 ตัว)
- หัวหน้าทีมเดินตามแบบหลวมๆ เป็นธรรมชาติ: ห่าง 30 px ปล่อยให้ห่างได้ 14 px ก่อนออกเดิน หยุดเบาๆ ยืนเยื้องข้างทาง หันมาหาเรา
- **โอเวอร์ไทม์ (กติกาใหม่ของเจ้าของเกม):** เทิร์น 1–80 ปกติ หลังจากนั้นดาเมจทุกครั้ง ×1.2 ต่อเทิร์นแบบทบต้น (1.2, 1.44, 1.73, 2.07…) แทนเดิม (เริ่มเทิร์น 48 +6%/เทิร์น และหมดเวลาที่ 80) — หยุดฉุกเฉินที่ 200 (`HARD_TURN_LIMIT`); หน้าเทิร์นเบสแสดงตัวคูณสีแดงแทน "/80"

## ระยะที่ 3 (2026-11-14)
- **ไม่ต้องเดินไปชิดมอน:** คลิกมอน (หรือฟาร์มออโต้) ตัวละครเดินไปแค่ระยะ `FARM.reach` 70 px ที่มองเห็นมอนได้ไม่มีอะไรบัง แล้วหัวหน้าทีมเดินเข้าไปสู้เอง — การ์ดข้อมูลมอนยังเปิดได้จากปุ่ม "ดู" เมื่อยืนข้างมอน
- **เคอร์เซอร์เมาส์ของเราเอง** (`ui/cursor.ts`, พิกเซล 16×16 แสดง 2 เท่า): ถุงมือเกราะชี้นิ้วตามภาพของเจ้าของเกม และ **ดาบ** เมื่อชี้มอนที่สู้ได้ — มอนที่ชี้มี **เส้นขอบขาว-แดง** รอบรูป (`world/outline.ts`)
- ต้นไม้/กำแพงที่บังจะโปร่งแสงเมื่อบัง **หัวหน้าทีม** และ **มอนที่กำลังสู้** ด้วย (ไม่ใช่แค่ตัวละครหลัก)

## ระยะที่ 4 (2026-11-14)
- มอนที่กำลังถูกสู้ **หันหน้าหาหัวหน้าทีม** ที่ตีมันอยู่ ไม่ใช่ตัวละครหลัก
- เคอร์เซอร์เมาส์ **ปิดไว้ก่อน** (เจ้าของเกมจะวาดใหม่ แล้วบอกตอนให้ใส่กลับ — โค้ดยังอยู่ใน `ui/cursor.ts`) เส้นขอบขาว-แดงตอนชี้มอนยังอยู่
- แถบการต่อสู้: "×3" เปลี่ยนเป็น "3 ตัว" (จำนวนมอนในกลุ่ม ไม่ใช่ความเร็ว) และป้าย "ออโต้ x2"
- ปุ่ม AUTO เดิม → **ปุ่มฟาร์ม** ฟาร์มมอนตัวไหนก็ได้ **ไม่มีล็อก** (`FARM.needWin` = false) ไม่หยุดเองเมื่อทีมเหลือแค่หัวหน้า — สู้ไม่ได้ก็ล้มทั้งทีม
- ใต้ปุ่มฟาร์มมี **สวิตช์ AUTO** (`player.settings.autoFight`, เปิดเป็นค่าเริ่มต้น): เปิด = ทุกการสู้ (โดนจับ/คลิก/ฟาร์ม) สู้บนแผนที่แบบออโต้; ปิด = เข้าหน้าเทิร์นเบส

## ระยะที่ 5 (2026-11-14)
- **ตีก่อนเข้าหน้าต่อสู้:** เมื่อปิด AUTO (หรือกด "ต่อสู้" บนการ์ด) หัวหน้าทีมเดินเข้าไปตีมอนบนแผนที่ 1 ที (ถ้ามอนจับเราได้ มอนตีก่อน) แล้วค่อยเข้าหน้าเทิร์นเบส (`world/Opener.ts`) — เป็นแค่ฉาก การต่อสู้จริงเริ่มในหน้าเทิร์นเบส
- **"ดูบนแผนที่" ย้ายเข้าเมนูตั้งค่า (⚙)** ของหน้าเทิร์นเบส คู่กับ "เล่นต่อ" และ "หนี" — ปุ่มมีสีของตัวเอง: เล่นต่อ เขียว, ดูบนแผนที่ ฟ้า, หนี แดง
- **แถบการต่อสู้บนแผนที่** แสดงแค่ชื่อมอน เลเวล และเลือด (ทั้งกลุ่ม) + ปุ่ม "หน้าต่อสู้" — **ไม่มีปุ่มหนี** (อยากหนีให้เดินออกเอง); บนมือถือแนวตั้งอยู่ด้านบน ระหว่างมินิแมพกับเมนูข้าง

## ระยะที่ 6 (2026-11-14)
- **คลิกมอน = สั่งโจมตี ไม่ใช่เดินไปตรงนั้น** (แบบตัวตีไกลใน LoL): ถ้ามอนอยู่ในระยะ 70 px และไม่มีอะไรบัง ตัวละครยืนนิ่ง หัวหน้าทีมเดินเข้าไปตีเอง; ถ้าไกลเกิน เดินไปแค่จนเข้าระยะแล้วหยุด — อยากเดินไปชิดมอนให้คลิกพื้นข้างๆ มอนแทน (`Controls.taken`, `WorldScene.inReach`)

## ระยะที่ 7 (2026-11-14)
- คลิกมอนที่อยู่ไกล: เดินเข้าระยะโดย **ไม่ขึ้นลูกศรเขียว** (เป็นคำสั่งตี ไม่ใช่คำสั่งเดิน)
- **สั่งเดินระหว่างกำลังเดินเข้าไปตี = ยกเลิกคำสั่งตี** (คลิกพื้น ปุ่มลูกศร/WASD จอยสติ๊ก) — อยากตีใหม่ให้คลิกมอนอีกครั้ง แบบ LoL; **แต่ถ้าสู้กันอยู่แล้ว เดินได้ตามปกติ** การสู้ยังดำเนินต่อ จะจบ (หนี) ก็ต่อเมื่อเดินออกเกินระยะ `FIELD_FIGHT.leash`

## ระยะที่ 8 (2026-11-14)
- **ใครตีล่าสุดอยู่เลเยอร์บน:** หัวหน้าทีมตี → หัวหน้าอยู่บน; มอนตี → มอนอยู่บน สลับกันไปตามจังหวะ (`strikerOnTop`) ทั้งตอนสู้บนแผนที่และฉากตีก่อนเข้าหน้าต่อสู้

## ยังไม่ทำ (ระยะต่อไป)
- ออนไลน์: เซิร์ฟเวอร์เดินเกมเดียวกัน แล้วส่งเหตุการณ์ (ใครออกท่า ผลแต่ละเป้า) ให้ผู้เล่นใกล้ๆ วาดด้วย `FieldFight` แบบ "ดูอย่างเดียว"
- รางวัล/EXP หลังชนะ (ยังไม่มีทั้งสองโหมด)

## ผลที่ตามมา
- เดินในทุ่งหญ้ามีแรงกดดัน: มอนเห็นแล้วไล่ หนีได้ถ้าเดินออก
- สู้มอนอ่อนได้เร็วโดยไม่ต้องเปลี่ยนหน้าจอ; มอนยาก/บอสเปิดหน้าเทิร์นเบสได้ทุกเมื่อ
- โครงพร้อมสำหรับฟาร์มออโต้และการเห็นกันบนแผนที่ เพราะการแสดงผลบนแผนที่อ่านจากผลของเกมอย่างเดียว
