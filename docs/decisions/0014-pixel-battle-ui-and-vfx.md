# 0014 — หน้าต่อสู้แบบพิกเซลทั้งหมด + VFX ของเราเอง

- สถานะ: Accepted (แทนส่วน "หน้าจอ" ของ ADR 0013; การจัดวางแบบ LineRanger_TurnBased ยังเหมือนเดิม)
- วันที่: 2026-11-10

## บริบท
- เจ้าของเกมบอกว่าหน้าต่อสู้ "ดูกากเกินไป" และส่งภาพตัวอย่าง VFX แบบพิกเซลมาให้ดู:
  - LEVEL UP มีเสาแสงและตัวอักษรหล่นลงมาทีละตัว
  - แถบเลือดมีหัวใจ แบ่งเป็นช่อง ส่วนที่หายไปกลายเป็นสีขาว มีประกายไฟ แล้วค่อยลดลง
  - ตัวเลขดาเมจเด้งออกมาพร้อมวงคลื่น แล้วสลายเป็นจุด
  - ×5 COMBO แบบกลิตช์
  - คริติคอลมีดาวแฉกและป้าย CRIT
  - เครื่องหมาย "!" เด้งขึ้น
- เจ้าของเกมขอให้ทำ UI หน้าต่อสู้ใหม่ทั้งหมดให้เป็นพิกเซล "เหมือนเกมคุณภาพ" และใช้ PixelLab ได้

## การตัดสินใจ

### สิ่งที่เกิดบนสนาม วาดเป็นพิกเซลบนสนามเอง
- `fx/BattleLayer.ts` เป็นแคนวาสขนาดเท่าที่กล้องเห็น หน่วยเป็นพิกเซลของแผนที่ วางทับสนาม
  - ทุกเฟรมจะลบแล้ววาดใหม่ด้วย engine ของเรา (`fx/surface.ts`)
  - พิกเซลของเอฟเฟกต์จึงคมและใหญ่เท่าพิกเซลของตัวละครพอดี
- เอฟเฟกต์ทั้งหมดอยู่ใน `fx/effects/battlePops.ts` เป็นดีไซน์ของเราเอง (เลียนแบบความรู้สึก ไม่ได้ลอกภาพ):
  - **DamagePop**
    - ตัวเลขเด้งออกมาใหญ่แบบกลวง แล้วหดลงเข้าที่พร้อมแสงวาบ
    - มีวงคลื่นกระแทกและประกายไฟ จากนั้นลอยขึ้นแล้วสลายด้วย ordered dither
    - ลูกศร ▲/▼ บอกว่าโดนจุดอ่อนธาตุหรือถูกต้านทาน
    - **คริ** ตัวใหญ่ขึ้นสองเท่า มีดาวแฉกสีส้มหมุนอยู่ข้างหลัง ป้าย CRIT สีแดง และวงทอง ตอนท้ายเหลือเป็นตัวเลขขาวกลวง แล้วเรืองหาย
  - **ComboBanner**: "×n COMBO" กลิตช์เข้ามาพร้อมเส้นความเร็ว มีวงแสงเต้นและแถบที่เติมเต็ม แล้วกลิตช์ออก
    - นับจำนวนครั้งที่ทีมเราตีโดนติดกัน ตาของมอนสเตอร์จะตัดคอมโบ
    - แสดงตั้งแต่ครั้งที่ 2 วางไว้ใต้ป้าย VS
  - **Alert** "!" สีทองเด้งขึ้นพร้อมประกาย ใช้เตือนก่อนมอนสเตอร์ใช้สกิล
  - **Pillar**: เสาแสงพุ่งขึ้นจากพื้น มีวงแสงที่เท้า ตัวอักษรหล่นลงมาทีละตัวพร้อมรัศมี แล้วเสาสลายเป็นประกาย ใช้ในสองกรณี:
    - ตอนได้บัฟ เช่น ATK UP / SHIELD / REGEN
    - ตอนชนะ: VICTORY! ตัวใหญ่กลางสนาม
  - **Slash** รอยฟันโค้งของอาวุธระยะประชิด
  - **Impact** แสงดาว วง และประกายตรงจุดที่โดน
  - **Bolt** ลูกพลังพร้อมหางของสายยิงและสายเวท ใช้แทนวงกลมเดิมของ Phaser
  - **HpBar** แถบเลือดพิกเซลเหนือหัวทุกตัว แทนแถบ HTML เดิม
    - กรอบมืด อัญมณีสีธาตุที่ปลายแถบ ช่องแบ่งเป็นปล้อง มินิบอสมีมงกุฎ
    - ตอนโดนตี ส่วนที่หายไปเป็นสีขาว กรอบกะพริบ มีประกายกระเด็นจากรอยตัด แล้วค่อยลดลง
    - ฮีลจะเรืองเข้ามา โล่เป็นแถบฟ้าอ่อนด้านบน
    - ตอนเล็งท่า แถบจะกะพริบบอกว่าจะโดนเท่าไร
  - ลูกศรทองเหนือตัวที่ถึงตา และวงเล็งที่มุมรอบเป้าที่เลือกได้ (ตัวที่ชี้อยู่เป็นสีขาว)
- **ฟอนต์พิกเซลของเรา** `fx/pixelFont.ts`
  - ตัวอักษรเส้นบางบนตาราง 4×6
  - มีแบบตัวหนา (เพิ่มเส้นไปทางขวา) และแบบขยายสองเท่า
  - ลงสีไล่จากบนลงล่าง มีขอบมืด เงา และแสงเงาด้านบน
  - ขยายจากกลางตัวได้ สลายด้วย dither ได้ เอียงหรือเลื่อนเป็นแถวแบบกลิตช์ได้
  - ใช้ได้ทั้งบนสนามและใน HUD (`textCanvas` วาดลงแคนวาสเล็กแล้วแสดงแบบ pixelated)
  - ใช้กับตัวเลขและคำภาษาอังกฤษสั้นๆ เท่านั้น ข้อความภาษาไทย (ชื่อ สถานะ สกิล) ยังใช้ Kanit

### HUD (HTML) เป็นพิกเซลบนตารางเดียว (แก้รอบสอง)
- รอบแรกใช้กรอบจาก PixelLab ชุดเดียว 9-slice ทุกชิ้น เจ้าของเกมติว่า:
  - กรอบซ้ำจำเจ
  - บิดเบี้ยว: กรอบ ฟอนต์ และไอคอนมีขนาดพิกเซลไม่เท่ากัน ไอคอนถูกย่อจนเพี้ยน
  - ตำแหน่งแปลก
  - ตัวเลขอ่านยาก
  - เลเยอร์ทับกัน: แถบเลือดและป้ายสถานะของตัวแถวหลังทับตัวข้างหน้า
- ทำใหม่ทั้งหมด:
  - **ตารางพิกเซลเดียว** `--p` = จำนวนเต็ม CSS px ต่อพิกเซล (`pixelSize()`: 2–4 ตามขนาดจอ)
    - ทุกกรอบ ไอคอน และตัวเลขใช้ขนาดนี้
    - รูปภาพแสดงที่ขนาดจริง × จำนวนเต็มเท่านั้น (`sized()`) ไม่ย่อ ไม่ยืด
  - **กรอบวาดด้วยโค้ดของเรา** `ui/pixelKit.ts` แต่ละส่วนรูปทรงไม่ซ้ำกัน:
    - แผงการ์ด: ขอบเหล็กน้ำเงิน ตัดมุมเฉียง มีแถบทอง
    - ป้ายเทิร์น: แปดเหลี่ยมทองบนพื้นแดงไวน์
    - แถบเลือดทีม: สี่เหลี่ยมด้านขนานเอียงออกจาก VS (ฟ้า / แดง)
    - ปุ่มโจมตีปกติ: สี่เหลี่ยมเหล็ก
    - ปุ่มสกิล: แปดเหลี่ยมทองมีหมุดอัญมณี
    - ลำดับเทิร์น: ชิป ตัวถัดไปเป็นสีทองและใหญ่กว่า
    - ป้ายระดับ: ริบบิ้นหางนกนางแอ่น
    - ปุ่มเล็ก แผ่นตัวเลข หน้าต่างรูปตัวละคร
  - **ไอคอน** `fx/pixelIcons.ts` ใช้ชุดเดียวกันทั้ง HUD และบนสนาม: สถานะต่างๆ, สัญลักษณ์ธาตุ 5 แบบ, คริสตัล, หัวใจ, เฟือง, เร่งความเร็ว
  - **ฟอนต์พิกเซลเปลี่ยนเป็น 5×7** แบบคลาสสิก อ่านง่าย
- **ตำแหน่ง:**
  - ซ้ายบน: เทิร์น + ลำดับ (จำนวนชิปปรับตามความสูงจอ)
  - กลางบน: เลือดทีม + VS
  - ขวาบน: ปุ่ม
  - ซ้ายล่าง: การ์ดตัวที่ถึงตา (รูป, ระดับ, ชื่อ, LV, ธาตุ/อาชีพ, เลือด, สถานะเป็นภาษาไทย)
  - ขวาล่าง: คริสตัลพลังงาน + ท่า 3 ปุ่ม
  - กลางจอโล่งไว้ให้สนาม
  - จอมือถือแนวตั้ง: การ์ดซ้อนอยู่เหนือท่า และ `hudReserve()` ให้กล้องจัดสนามให้พอดีช่องว่างที่เหลือ
- **เลเยอร์:**
  - ระยะห่างระหว่างแถวกว้างขึ้นเป็น 40 px แถบเลือดจึงไม่ทับตัวข้างหลังอีก
  - ป้ายสถานะ HTML ที่ลอยเหนือหัวเปลี่ยนเป็นไอคอนพิกเซลบนแถบเลือด (`BattleLayer`)
  - ชื่อสถานะเต็มอยู่ในการ์ด

### แก้รอบสาม: พิกเซลยังเพี้ยนบนจอสเกล 125%
- **ต้นเหตุ:** จอของเจ้าของเกมตั้งสเกล Windows ไว้ 125% ทำให้ `--p` = 3 CSS px กลายเป็น 3.75 พิกเซลจริง พิกเซลจึงกว้างไม่เท่ากัน ขอบดูเบลอและเบี้ยว
- **แก้:**
  - `pixelSize()` เลือกจำนวน**พิกเซลจริง**ที่เป็นจำนวนเต็มก่อน แล้วค่อยหารด้วย `devicePixelRatio` เช่น 4 พิกเซลจริงที่ 125% = 3.2 CSS px
  - เลิกจัดกึ่งกลางด้วย `translate -50%` ซึ่งทำให้เหลือเศษครึ่งพิกเซล
  - เลิกใช้แสงเรืองนุ่ม (drop-shadow) บนงานพิกเซล ท่าที่เลือกอยู่ใช้วงเล็บมุมสีทองแบบพิกเซลกะพริบแทน (`select` ใน kit)
  - เอาจุดทองที่หลงอยู่บนแผงการ์ดออก

### แก้รอบสี่: ทันสมัยขึ้น, ลำดับเทิร์นเลื่อนได้, จัดใหม่
- **ลำดับเทิร์น:** เดิมสร้างใหม่ทุกเทิร์นจึงเด้งตลอด ตอนนี้ชิปผูกกับตัวละครแต่ละตัว
  - ทุกเทิร์นชิปจะเลื่อนไปยังตำแหน่งใหม่ (FLIP ด้วย `element.animate`)
  - ตัวที่เพิ่งเล่นไปเลื่อนลงไปต่อท้ายคิว ตัวอื่นเลื่อนขึ้น
  - ตัวที่หลุดออกจากรายการเลื่อนออกทางซ้าย ตัวใหม่ลอยขึ้นมา
  - ตัวถัดไปค่อยๆ ขยายเป็นกรอบทอง มีลูกศรชี้
- **กรอบ:** เปลี่ยนเป็นสไตล์แบนทันสมัย พื้นกระจกมืด ขอบบางสว่าง มีสีเน้น
  - ปุ่มท่าเป็นวงกลม: โจมตีปกติเป็นวงเหล็ก สกิลเป็นวงทองมีอัญมณี 4 เม็ด
- **ตำแหน่ง:**
  - การ์ดตัวละคร, เกจพลังงาน และปุ่มท่ารวมเป็นกลุ่มเดียวที่มุมซ้ายล่าง โดยเกจพลังงานอยู่เหนือปุ่มท่า ชิดกับการ์ด
  - คอมโบย้ายไปทางซ้าย ข้างลำดับเทิร์น
- **สนาม:** ซูมออก (สนามกว้างราว 360 × 160)
  - แถวหน้าห่างจากกลาง ±42
  - แถวหลังห่างจากกลาง ±94 ตัวกลางแถวหลังถอยไปที่ ±112
  - ระยะห่างระหว่างแถว 42

### แก้รอบห้า: ปุ่มสกิลตามแบบที่เจ้าของเกมส่งมา
- **กรอบ:** สี่เหลี่ยมตัดมุม เส้นนอกกรมท่า ขอบเหล็กขัดเงา 3 ชั้น (ด้านบนและซ้ายสว่าง)
  - ปุ่มสกิลมีมุมทองที่ซ้ายบนและขวาล่าง และมีชิ้นทองสั้นๆ ที่อีกสองมุม
  - ปุ่มโจมตีปกติเป็นเหล็กล้วน
- **พื้นหลังไอคอน:** วงเรืองสีธาตุของฮีโร่ ไล่ระดับแบบ dither เป็นพิกเซล ไม่ใช่ gradient นุ่ม (`glowUrl`)
- **ค่าพลังงาน:** ตัวเลขบนหกเหลี่ยมที่มุมขวาล่าง
  - ฟ้า = ใช้พลังงาน
  - เขียว = โจมตีปกติ ได้ +1
  - เทา = ติดคูลดาวน์ หรือพลังงานไม่พอ

### แก้รอบหก: หน้าจอมือถือแนวตั้ง
- **ปัญหา:** แถบเลือดล้นขอบจอ, ลำดับเทิร์นกับปุ่มทับสนาม และสนามเล็กนิดเดียว
- **จัดใหม่เป็นแถว** ไม่มีอะไรทับสนาม เรียงจากบนลงล่าง:
  1. เลือดทีม + VS เต็มความกว้าง (ซ่อนตัวหารกับจำนวนตัวที่เหลือ)
  2. ป้ายเทิร์น (ซ้าย) + ปุ่ม (ขวา)
  3. ลำดับเทิร์นเป็นแถวแนวนอน เลื่อนไปทางข้างได้
  4. สนาม
  5. การ์ดตัวละคร
  6. พลังงาน
  7. ท่า 3 ปุ่ม
- **สนาม:** ความกว้างที่ต้องพอดีจอแนวตั้งลดเหลือ 250 px
  - ถ้าซูมเป็นจำนวนเต็มแล้วได้ต่ำกว่า 2 เท่า (มือถือที่พิกเซลจริงน้อย) จะใช้ซูมพอดีช่องว่างแทน ตัวละครจึงไม่เล็กเกินไป

### แก้รอบเจ็ด: แถบล่างตาม wireframe + ทีมพิเศษ
- **แถบล่าง** เรียงตามแบบที่เจ้าของเกมวาด:
  - การ์ด: รูปฮีโร่ + ดาว C0–C5 ด้านล่าง | สถานะบัฟ/ดีบัฟ → เลือด → ชื่อ + เลเวล → ธาตุ + อาชีพ
  - ปุ่มตีปกติ
  - เกจพลังงานเหนือสกิล 1 และ 2
  - ทีมพิเศษ 2 ตัว: รูป (กรอบม่วง ป้าย ASSIST) + ปุ่มสกิล 1 ที่มีค่าพลังงานบนหกเหลี่ยม ตอนพักจะมืดและขึ้นจำนวน "n เทิร์น"
- **จอเล็ก:**
  - มือถือแนวตั้ง: การ์ด / ตีปกติ + สกิล / ทีมพิเศษ เรียงเป็นแถว
  - จอแนวนอนที่แคบ: ทีมพิเศษขึ้นไปอยู่ด้านขวา
- **VFX อัญเชิญ:** `SummonCircle` คือวงเวทบนพื้น มีวงแหวน 2 ชั้น อักขระหมุน และดาวหกแฉกหมุนสวนทาง มีละอองแสงลอยขึ้น
  - มีเสาแสงลงมา ตัวละครปรากฏเป็นสีขาวก่อน แล้วค่อยเป็นตัวจริง
  - cut-in "ASSIST" สีม่วง
  - ตอนกลับ: วงพับเก็บพร้อมแสงระเบิด ตัวละครจางหาย

### แก้รอบแปด: รื้อแถบล่างทิ้ง แล้วทำใหม่ให้ตรง wireframe ทุกช่อง
- แถบล่างเป็น CSS grid ของช่อง (tile) ตามแบบเป๊ะ ทุกช่องมีขนาดเป็นพิกเซลเต็ม และช่องสี่เหลี่ยมมีขนาด 48 พิกเซล
- **ซ้ายล่าง (`.bt-dock`):**
  - รูปฮีโร่ (48×48) และดาวอยู่ข้างใต้
  - สถานะบัฟ/ดีบัฟพาดยาวด้านบน ครอบช่องเลือดและช่องตีปกติ
  - เลือด: แสดงตัวเลขอย่างเดียว ไม่ใส่ /max
  - ชื่อ + LV / ธาตุ + อาชีพ
  - ตีปกติ (สูงเท่าช่องเลือดกับช่องชื่อรวมกัน)
  - เกจพลังงาน (คริสตัล 10 เม็ด + ตัวเลข) อยู่เหนือสกิล 1 และ 2
- **ขวาล่าง (`.bt-assist`):** รูปฮีโร่ทีมพิเศษ + สกิล 1 ของแต่ละตัว
- ช่องข้อความเป็นกระจกมืดแบน (`k-tile`) ปุ่มท่าใช้กรอบเหล็ก/ทองขนาด 48
- **จอแนวนอนแคบ:** ทีมพิเศษขึ้นไปอยู่ด้านขวาเหนือแถว
- **มือถือแนวตั้ง:** ใช้ช่องชุดเดียวกัน เรียงเป็นแถว แถวละ 4 ช่อง
  - เรียงจากบนลงล่าง: การ์ด / พลังงาน / ท่า / ทีมพิเศษ
  - ขนาดพิกเซลย่อลงให้ 4 ช่องพอดีความกว้างจอ ตัวอักษรไทยไม่เล็กกว่า 11px
- ตัวเลขเลือดทีมด้านบนก็แสดงแค่ตัวเลขเหมือนกัน

### แก้รอบเก้า
- **สลับตำแหน่ง:** เกจพลังงานไปอยู่ซ้ายบน (เหนือเลือด / ชื่อ / ตีปกติ) ส่วนบัฟ/ดีบัฟย้ายไปขวาบน
  - บัฟ/ดีบัฟไม่มีกรอบแล้ว แสดงเป็นไอคอนขนาด 2 เท่า มีตัวเลขเทิร์นที่มุม ถ้าไม่มีสถานะช่องนี้จะว่างไปเลย
- **หลอดเลือดและพลังงาน:** เป็นหลอดพิกเซลแบบแบ่งช่อง (`ui/pixelBar.ts`) วาดด้วย engine ของเรา พลังงานเป็นสีฟ้า 10 ช่อง
  - ตอนลด: ส่วนที่หายเป็นสีขาวครีมค้างไว้ กรอบกับไอคอนกะพริบ มีประกายไฟจากรอยตัด แสงพองข้างหลัง แล้วค่อยไหลลดลงโดยมีหัวสว่างนำ
  - ตอนเพิ่ม: ช่องใหม่วาบขาวแล้วค่อยกลับเป็นสีเดิม มีประกายที่ขอบ
- **ท่าที่เลือก:** มีแสงวิ่งวนรอบกรอบ 2 ดวง พร้อมหางแสงและประกาย (`ui/pixelSwirl.ts`) แทนวงเล็บมุม
- **ปุ่มลัด Z/X/C และหกเหลี่ยมค่าพลังงาน:** ขยับเข้ามาอยู่ในกรอบ ไม่ยื่นออกนอก
- **กรอบรูปฮีโร่ตามระดับ (`rarityWindow`):**
  - Rare ฟ้า / Epic ม่วง / Legend ทอง มีแสงรัศมี / Mythic แดงม่วงดำ มีเปลวมืด
  - มีขอบโลหะตามสีระดับ อัญมณีที่ 4 มุม (Legend และ Mythic มีอัญมณีบนยอดเพิ่ม) และประกายระยิบ
  - ทีมพิเศษใช้กรอบตามระดับแบบเดียวกัน และไม่มีคำว่า ASSIST แล้ว

### แก้รอบสิบ
- **หลอดเลือดและหลอดพลังงาน:** ยาวเท่ากัน
  - หลอดเลือดยาวเต็มช่อง ตัวเลขวางทับบนหลอดแทนการอยู่ข้างๆ
  - ช่องพลังงานอยู่เหนือช่องเลือดพอดี ส่วนบัฟ/ดีบัฟขยับไปกินพื้นที่ด้านขวา
- **ท่าที่เลือก:** ไม่เด้งขึ้นลงแล้ว (ตอนชี้เมาส์แค่สว่างขึ้นเล็กน้อย)
  - แสงวนอยู่ใต้ตัวเลขค่าพลังงานกับปุ่มลัด ไม่ทับกัน
  - กรอบสกิลเป็นสีทองทั้งกรอบ
- **รูปในกรอบ:** วางกึ่งกลางตามส่วนที่วาดจริงของภาพ (วัดจากพิกเซลที่มีสี) อยู่ในพื้นที่ด้านใน 40×40 ของกรอบ
- **มอนสเตอร์มีระดับเหมือนฮีโร่:** ร่างแรกคือมอนสเตอร์ทั่วไป Rare มินิบอส Epic
  - ใช้กรอบรูปตามระดับ และมีป้ายระดับในการ์ดมอนสเตอร์
- **สนามบน PC:**
  - กล้องวางให้เท้าของตัวที่อยู่ล่างสุดอยู่เหนือแผงล่างพอดี
  - ซูมให้ใหญ่ที่สุดเท่าที่พอดี ส่วนแถบด้านบนทับได้แค่ต้นไม้ด้านหลัง
  - ถ้าจอแคบจนแถวล่างไม่พอ จะลดขนาดพิกเซลของ UI ลงทีละพิกเซลจริงให้ทั้งแถวพอดี แทนการย้ายทีมพิเศษขึ้นไปบังสนาม
- **จอสั่น:** เบาลงและสั้นลง

### แก้รอบสิบเอ็ด: ตราอัญเชิญใหม่ + เลเยอร์
- **เลเยอร์:** เพิ่มชั้นเอฟเฟกต์บนพื้น (`BattleLayer` ที่ depth 1.45 อยู่ใต้ตัวละคร) วงเวทจึงอยู่ใต้เท้าฮีโร่ที่ถูกเรียกมา ไม่ทับตัวเหมือนก่อน
  - เสาแสงกับประกายยังอยู่ชั้นหน้าเหมือนเดิม
  - ชั้นที่ว่างจะไม่วาดซ้ำทุกเฟรม
- **ตำแหน่งที่เรียกลงมา:** เลือกจุดรอบตัวที่เรียกที่ห่างจากตัวอื่นมากที่สุด จะได้ไม่ซ้อนกัน
- **ตราอัญเชิญ:** ทำตามภาพตัวอย่างของเจ้าของเกม
  1. ละอองแสงลอยเข้ามารวมเป็นวงบนพื้น
  2. วงสว่างขึ้น มีวงที่สอง อักขระหมุนรอบ และดาวหกแฉกหมุนสวนทาง
  3. เสาแสงพุ่งลงมาจากด้านบน แกนขาว รอบนอกม่วงอ่อน ขอบเป็นม่วงแบบ dither มีแสงวาบกับวงแหวนระเบิดออกตรงที่ลงพื้น และละอองไหลขึ้นตามเสา
  4. ตอนจบ: เสาหดเป็นเส้นแล้วหายไป วงเวทวาบแล้วหดสลายเป็นละออง

### แก้รอบสิบสอง: แสงวาปตอนมาและตอนกลับ
- **ปัญหาเดิม:** เสาแสงค้างตลอดการร่ายสกิล จนกว่าฮีโร่จะกลับ จึงดูเหมือนไม่หายไปเลย
- **ตอนมา:** เสาแสงพุ่งลงมา ค้างไว้ 0.5 วิ (`BEAM_HOLD`) แล้วหดบางหายไปเอง ระหว่างร่ายเหลือแค่วงเวทจาง ๆ ใต้เท้า
- **ตอนกลับ** (`SummonCircle.close()`):
  - มีเสาแสงวาปพุ่งขึ้นจากพื้น พร้อมประกายไหลขึ้น
  - ฮีโร่กลายเป็นสีขาว ลอยขึ้น 10 px แล้วจางหายไปในแสง (`BattleStage.sendBack`)
  - เสาหดบางลงจากด้านล่างขึ้นไป แล้ววงเวทจึงหดสลาย

### แก้รอบสิบสาม: มือถือ (จอตั้ง)
- **หน้า VS ตอนเริ่ม:** เดิมวางทีมเรา–โล่ VS–ทีมศัตรูเป็นแถวเดียว กว้างเกินจอมือถือ ตอนนี้เรียงจากบนลงล่าง: หน้าทีมเรา โล่ VS (ขนาดเท่าเดิม 2 เท่า) BATTLE START แล้วหน้าทีมศัตรู แถบดำสูงขึ้นให้พอ
- **หลอดพลังงาน:** ย้ายขึ้นไปไว้บนสุดข้างรูปฮีโร่ (ตรงกับจอ PC) สถานะอยู่ข้างหลอด ถ้ามีเกินช่องจะขึ้นแถวใหม่ด้านบน แผงล่างจึงเตี้ยลงหนึ่งแถว และกล้องได้ที่ให้สนามเพิ่ม
- **สกิลที่มอนสเตอร์ไม่มี** (เช่นผึ้งมีสกิลเดียว): เดิมขึ้นว่า "9998 เทิร์น" จากค่าสำรอง ตอนนี้เป็นกรอบเปล่าสีหม่น

### แก้รอบสิบสี่: หลอดเลือด–พลังงานเต็มช่อง
- **ความยาว:** หลอดเลือดกับหลอดพลังงานยาวเท่ากันเสมอ และยาวเต็มช่องที่อยู่ (`BAR_W`)
  - PC: 92 px ในคอลัมน์ 96
  - มือถือ: 146 px เต็มสามช่อง
  - `PixelBar.resize()` เปลี่ยนความยาวเมื่อจอเปลี่ยนแบบ
- **ช่องในหลอด:** แบ่งเป็นเปอร์เซ็นต์ทั้งสองหลอด 10 ช่อง ช่องละ 10 % ไม่ผูกกับความยาวหลอด
- **บัฟ/ดีบัฟบนมือถือ:** ย้ายไปอยู่เหนือแผงล่างทางขวา เพราะหลอดพลังงานใช้เต็มแถวแล้ว ถ้ามีเยอะจะซ้อนขึ้นเป็นแถว

### แก้รอบสิบห้า: เกจพลังงานคริสตัล
เกจพลังงานแบบใหม่ เขียนเองใน `ui/energyGauge.ts` ไม่ใช้หลอดแบบเดียวกับหลอดเลือดแล้ว

- **หน้าตา:**
  - ปลายซ้ายเป็นคริสตัลเจียระไน ด้านซ้ายสว่าง ด้านขวาเข้ม มีจุดประกาย
  - ตามด้วยช่องคริสตัลเอียง 10 ช่อง (ช่องละ 10 %) แต่ละช่องมีกรอบของตัวเอง
  - ช่องที่เต็มเป็นแก้วสีฟ้า ขอบบนสว่าง มีเส้นประกายเฉียง ช่องว่างเป็นแก้วมืด
- **ตอนพลังงานเพิ่ม:** ช่องใหม่สว่างขึ้นทีละช่อง วาบขาวแล้วค่อยกลับเป็นสีฟ้า มีประกายทุกช่อง
- **ตอนใช้พลังงาน:** ช่องที่ใช้ไปวาบขาว ค้างไว้แล้วจางลง แตกเป็นเศษประกาย คริสตัลกะพริบทั้งตอนเพิ่มและตอนลด
- **ตอนเต็ม:** มีแสงวิ่งผ่านทั้งเกจทุกสองวินาที คริสตัลเรืองแสง
- **ขนาด:** เท่ากับหลอดเลือดเสมอ (สูง 12 px ยาวเต็มช่อง)
- **ไอคอนใหญ่ขึ้น:** ทั้งสองหลอดมีไอคอนใหญ่ที่ปลายซ้าย
  - หัวใจ `HEART_BIG` ขนาด 13×11 px สูงเท่าหลอด
  - คริสตัลสูงกว่าหลอดด้านละ 2 px
  - ช่องในหลอดเริ่มใต้ขอบขวาของไอคอน
  - ตัวหลอดไม่ได้ใหญ่ขึ้น
- **ช่องติดกัน:** เกจพลังงานเปลี่ยนจากเม็ดคริสตัลแยกกัน มาเป็นหลอดเดียวแบบหลอดเลือด
  - กรอบมืดกรอบเดียว ช่อง 10 ช่องติดกัน คั่นด้วยรอยบาง ๆ ที่เอียงนิดหน่อย
  - ยังมีประกายในแต่ละช่อง และ FX ตอนเพิ่ม ลด และเต็มเหมือนเดิม

### แก้รอบสิบหก: ทรานซิชั่นเข้าสู้บนมือถือ
- **ปัญหาเดิม:** บนจอตั้งมีมุมของใบมีดที่ปิดไม่มิด มองเห็นแผนที่ลอดออกมา
  - ขอบใบมีดเอียงได้ถึงหนึ่งในหกของความสูงจอ แต่ใบมีดวิ่งเลยขอบจอไปแค่ 20 px
  - พอจอสูงเกินประมาณ 300 px มุมล่างของใบมีดจึงไปไม่ถึงขอบ
- **แก้:** ใบมีดเริ่มนอกจอและวิ่งเลยขอบอีกด้านไปเท่ากับระยะเอียงสูงสุดบวก 20 px (`edge()` ใน `battleCut.ts`) จอทุกรูปทรงจึงปิดมิด

### แก้รอบสิบเจ็ด: แผ่นรองของทีมพิเศษ
- **ปัญหาเดิม:** รูปของตัวในทีมพิเศษกับสกิลของตัวนั้นวางห่างกันเท่ากับช่องอื่น ๆ จนดูไม่ออกว่าสกิลไหนเป็นของใคร
- **แก้:** แต่ละคู่ (รูป + สกิล 1) วางบนแผ่นรองสีดำของตัวเอง (`.bd-pair`)
  - ขอบบางสีเทาอมฟ้า ขอบบนสว่างกว่า มุมตัดหนึ่งขั้น
  - แผ่นยื่นพ้นช่องออกไป 2 px ทุกด้าน
- **ระยะระหว่างสองคู่:** PC 8 px มือถือ 3 px (จอมือถือพอดี 207 px)
- **ไม่กะพริบ:** เลิกให้รูปของตัวในทีมพิเศษกะพริบสว่างตอนเรียกได้ เจ้าของเกมบอกว่ารบกวนสายตา (ตอนที่เลือกอยู่ยังสว่างขึ้นหนึ่งขั้นเหมือนเดิม) ปุ่มอัลติเมตตอนชาร์จเต็มก็เลิกกะพริบด้วย

### แก้รอบสิบแปด: ด้านบนบนมือถือ
- **ป้ายเทิร์นกับปุ่ม:** ขยับขึ้นมาอยู่ใต้หลอดเลือดทีมพอดี (ห่างจากด้านบน 34 px จากเดิม 46) ซ้าย–ขวาของโล่ VS
  - แถวลำดับเทิร์นจึงขึ้นมาด้วย
  - ที่เว้นด้านบนของกล้อง (`hudReserve`) ลดจาก 108 เป็น 96 px
- **เลขคอมโบ:** บนมือถือขึ้นตรงกลางจอ ใต้แถวลำดับเทิร์น (`railBottom()`) แทนที่จะชิดซ้าย

### แก้รอบสิบเก้า: สีและการเข้าของเลขคอมโบ
- **สี:** เริ่มสีเหลืองที่ ×2 แล้วไล่เป็นส้มจนแดงเต็มที่ ×12 ขึ้นไป (`comboLook` ใน `battlePops.ts`)
  - ตัวเลข ตัวอักษร วงแหวน แสง เส้นลม และแถบใต้คำเปลี่ยนสีตามกันหมด
- **การเข้า:** เลื่อนเข้ามาจากซ้ายไปขวาอย่างเร็วแล้วค่อยหยุด เข้ากับเส้นลมที่พุ่งไปด้านหลัง เหมือนมันพุ่งไปทางขวา
- **ตอนหาย:** เลื่อนต่อไปทางขวาพร้อมจางหาย

### แก้รอบยี่สิบ: การ์ดข้อมูลตอนเอาเมาส์ชี้ (PC)
เจ้าของเกมขอให้เป็นแบบเกมเดิมของเขา ทำด้วยกรอบพิกเซลของเรา ขึ้นเฉพาะเครื่องที่มีเมาส์ (`(hover: hover) and (pointer: fine)`) มือถือไม่มี

- **ชี้ฮีโร่หรือศัตรูบนสนาม** (รวมรูปบนการ์ดล่าง และรูปของทีมพิเศษ): การ์ดขึ้นข้าง ๆ ตัว
  - หน้า ชื่อ LV
  - ธาตุ · อาชีพ (มอนสเตอร์/มินิบอส) · ฝ่ายเรา/ศัตรู
  - หลอดเลือดกับ "เลือด / เลือดสูงสุด" และ %
  - พลังโจมตี เกราะ สปีด คริ (ค่าจริงตอนนั้น รวมบัฟ/ดีบัฟ)
  - สถานะพร้อมค่าและเทิร์นที่เหลือ
- **ชี้ปุ่มท่า** (ตีปกติ สกิล 1–2 อัลติเมต สกิลทีมพิเศษ): การ์ดขึ้นด้านบน
  - ไอคอน ชื่อ ค่าพลังงาน (ตีปกติ +1 · อัลติเมตแสดง % ที่ชาร์จ)
  - เป้า
  - ผลทีละบรรทัด สร้างจากข้อมูลสกิล (`effectLines`)
  - หมายเหตุวิธีใช้ (อัลติเมต · ทีมพิเศษพัก 8 เทิร์น · มอนสเตอร์ใช้ทุก n เทิร์น)
- **กรอบ:** กระจกมืด ขอบสีฝ่าย (ฟ้า/แดง สกิลเป็นทอง) มุมตัดหนึ่งขั้น (`k-tipAlly/Foe/Skill`)
- **อัปเดตเอง:** การ์ดเปลี่ยนตามเลือดและพลังงานระหว่างที่ยังชี้อยู่ และไม่ล้นขอบจอ
- เมื่อมีการ์ดแล้ว ปุ่มท่าบน PC จึงไม่มี tooltip ของเบราว์เซอร์อีก
- ปรับเครื่องหมายจุลภาคในฟอนต์พิกเซลให้มีหาง จะได้ไม่ดูเหมือนจุด ("6,440")
- **ชี้ได้ทุกตัว:** เดิมพื้นที่รับเมาส์ของตัวละครเปิดเฉพาะตัวที่เป็นเป้าได้ตอนนั้น ตอนนี้ทุกตัวรับเมาส์
  - ตัวที่เป็นเป้าได้ยังมีเคอร์เซอร์เล็งอยู่ตัวเดียว
  - กดตัวที่ไม่ใช่เป้าก็ไม่มีอะไรเกิดขึ้น
- **ปุ่มที่กดไม่ได้:** ส่งเมาส์ผ่านไปที่ช่องของมัน การ์ดจึงขึ้นได้แม้ปุ่มเป็นสีเทา
- **มือถือ/แท็บเล็ต:** กดค้าง 0.42 วิ (`LONG_PRESS_MS`) การ์ดขึ้นจนกว่าจะปล่อยนิ้ว
  - การกดครั้งนั้นไม่นับเป็นการแตะ (ไม่เลือกท่า ไม่เลือกเป้า)
  - แตะสั้นทำงานเหมือนเดิม
  - ปิดเมนูกดค้างของเบราว์เซอร์ในส่วนนี้

### แก้รอบยี่สิบเอ็ด: ไกด์ผลของท่าในการ์ด
ตอนเลือกท่าอยู่แล้วชี้ตัวที่ท่านั้นใช้ได้ การ์ดของตัวนั้นบอกว่าท่าจะทำอะไรกับมัน (`previewFor` ใช้ `previewAction` / `previewLoss` ของระบบต่อสู้) ไม่รวมดวง: คริ หลบ ต้านสถานะ

- **ดาเมจ:**
  - ส่วนของหลอดที่จะหายกะพริบสีขาว พร้อมตัวเลข "-n" สีแดงแทน %
  - ถ้าโดนโล่ก่อน บอกส่วนที่โล่รับ ("-n โล่")
  - ถ้าจะล้ม ขึ้น "ล้ม!"
  - ถ้ามีอมตะ ขึ้น "อมตะ · ไม่โดน"
- **ฮีล:** ส่วนที่จะเพิ่มกะพริบสีเขียว พร้อม "+n" สีเขียว
- **โล่:** แถบโล่กะพริบ พร้อม "โล่ +n"
- **สถานะ:** สถานะที่จะติด ลบบัฟ หรือล้างดีบัฟ ต่อท้ายสถานะเดิม เป็นป้ายเส้นประ
- **ไกด์:** มีบรรทัดบอกว่า "ถ้าใช้ <ท่า> กับตัวนี้ · ตัวเลขโดยประมาณ"
- **อัปเดตเอง:** เปลี่ยนท่าระหว่างที่ชี้อยู่ การ์ดเปลี่ยนตาม

### แก้รอบยี่สิบสอง: ไกด์กะพริบช้า + ทีมพิเศษใช้ได้ 2 สกิล
- **ไกด์ในการ์ด:** ส่วนของหลอดที่จะลด เพิ่ม หรือได้โล่ ค่อย ๆ จางแล้วสว่างกลับช้า ๆ (1.1 วิ ไล่ระดับ ไม่กะพริบเป็นจังหวะ)
- **ป้ายสถานะที่จะติด:** เปลี่ยนจากเส้นประเป็นพื้นสีอ่อน
  - ดีบัฟเป็นแดงอ่อน บัฟเป็นเขียวอ่อน
  - ถ้าเป้ามีสถานะนั้นอยู่แล้ว (จะถูกต่อเวลา) พื้นเป็นสีเข้มและไม่แสดงซ้ำ
  - ค่อย ๆ จางแล้วสว่างกลับช้า ๆ เหมือนกัน
- **ทีมพิเศษ:** เรียกมาใช้ได้ทั้งสกิล 1 และสกิล 2 (ตีปกติและอัลติเมตไม่ได้ — `canSummon`) ใช้สกิลไหนก็พักทั้ง 2 สกิลพร้อมกัน `RESERVE_COOLDOWN` เทิร์น
  - AI เลือกได้ทั้ง 2 สกิลอยู่แล้ว
  - เทสอัปเดตแล้ว
- **แผงทีมพิเศษ:** เอารูปโปรไฟล์และแผ่นรองออก เหลือปุ่มสกิล 4 ปุ่ม
  - ตัวแรก สกิล 1 / 2 ใช้ปุ่ม V / B ตัวที่สอง สกิล 1 / 2 ใช้ปุ่ม N / M
  - การ์ดตอนชี้บอกว่าเป็นสกิลของใคร
- **มือถือ:** แถวสกิลทีมพิเศษใช้ 4 คอลัมน์เดียวกับแถวท่าด้านบน (ไม่มีช่องคั่นกลาง) ได้ตาราง 2×4 ตรงกันทุกช่อง

## ผลที่ตามมา
- กรอบชุด PixelLab รอบแรก (15 generations) ไม่ได้ใช้แล้ว ลบออกแล้ว
- เพิ่มกรอบใหม่: เพิ่มใน `buildKit()` ของ `ui/pixelKit.ts` แล้วใช้คลาส `.k-<ชื่อ>` ใน `ui/battle.css`
- ตัวอักษรที่ฟอนต์พิกเซลยังไม่มี จะแสดงเป็นช่องว่าง ให้เพิ่มลงใน `G` ของ `fx/pixelFont.ts`
- ภาพ LEVEL UP ยังไม่ได้ใช้ เพราะระบบเลเวลและ EXP ยังไม่มี แต่ `Pillar` พร้อมใช้แล้ว
