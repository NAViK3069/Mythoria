# 0008 — NPC สร้างจากชิ้นส่วนของตัวละครหลัก

- สถานะ: Accepted
- วันที่: 2026-11-09

## บริบท
- ต้องการ NPC หลายคนตามเมือง/แมพ ยืนหน้าร้านและจุดสำคัญ มีชื่อบนหัว และกดคุยได้
- ลายเส้นต้องเหมือนตัวละครหลัก: หัว ตัว ขา 2 ข้าง บนเฟรม 32×32 ไม่มีแขน (ใช้มือลอย) — เปลี่ยนชุด ทรงผม สีตา

## การตัดสินใจ
- **หน้าตา** (`tools/npc_parts.py` → atlas `npcs`):
  - เริ่มจากร่างเปล่าของตัวหลัก (Hero00) — หัวโล้นที่มีหน้า/ตาเดิม
  - **ทรงผม/หมวก**: PixelLab inpaint (Pro Flash, 5 generations ต่อคน) โดย mask เฉพาะพื้นที่ผม (เหนือคิ้ว + ข้างหัว) ส่วนอื่นถูกคงไว้ทุกพิกเซล → หน้า ตา และตำแหน่งตรงกับตัวหลักพอดี
    - ภาพต้นทางต้องใส่เสื้อ (ใช้เสื้อ/รองเท้าของตัวหลัก) — ร่างเปล่าโดนตัวกรองเนื้อหาของ PixelLab ปฏิเสธ
  - หัวตัดกลับออกมาเฉพาะพื้นที่ผม + หน้า; สีตาเปลี่ยนที่พิกเซลตาสองจุดของตัวหลัก
  - **ชุด**: วาดเป็นตารางพิกเซลบนบล็อกลำตัวเดิม (x 10–22, y 18–27) แรเงาแบบเดียวกับเสื้อตัวหลัก (ซ้ายเข้ม หน้าสว่าง ขอบดำ 1 px) — ผ้ากันเปื้อน ชุดคลุม เกราะ เสื้อกั๊ก เครื่องแบบ ฯลฯ
  - **รองเท้า**: ขาตัวหลักเปลี่ยนสี
- **ในเกม** (`world/Npcs.ts`): ใช้ `MasterCharacter` ตัวเดียวกับผู้เล่น (ส่วนประกอบระบุเป็น `atlas#frame`) จึงขยับแบบเดียวกัน (หายใจ หัวเอียง มือลอย)
  - ยืนตามจุดใน `world/npcData.ts` (เลื่อนไปจุดว่างที่ใกล้ที่สุดถ้าทับของ) — ทุ่งหญ้าวางจากแคมป์และหมู่บ้านอัตโนมัติ
  - หันมามองเมื่อผู้เล่นเข้าใกล้; มี hitbox ที่เท้า (ผู้เล่นและสัตว์เดินทะลุไม่ได้); เลเยอร์ใช้ `MeadowView.depthFor`
  - ชื่อบนหัวเป็น HTML (ตัวไทยคม) อยู่ใต้เมนู แตะได้
- **การคุย** (`ui/talk.ts`): เดินใกล้ → ปุ่ม "แตะเพื่อคุย"/E; แตะตัวหรือชื่อ → เดินไปหาแล้วคุย
  - กล่องบทสนทนา: หน้าจากชิ้นส่วนของ NPC, ชื่อ, บทบาท, พิมพ์ทีละตัว (ไม่ตัดกลางสระ/วรรณยุกต์ไทย), ปุ่มเปิดหน้าต่าง + ลาก่อน
  - ระหว่างคุย ผู้เล่นหยุดเดิน (`Modal.addBlocker`)
- **ชื่อและบทพูดเป็นตัวแทนชั่วคราว** ตามบทบาท — รอเจ้าของเกม (`docs/game-design/npcs.md`)

## ผลที่ตามมา
- เพิ่ม NPC ใหม่: inpaint ทรงผม 1 ครั้ง → เพิ่มชุด/สีตา/รองเท้าใน `tools/npc_parts.py` → เพิ่มข้อมูลใน `npcData.ts`
- ชุดเดียวกันนี้ใช้ทำฮีโร่ลูกทีม/การแต่งตัวมาสเตอร์ต่อได้ (เปลี่ยนหัว/ตัว/ขาแบบ ProjectZ)
- ใช้ PixelLab ไป 85 generations (13 ทรง + ครั้งที่โดนตัวกรอง)
- ทดสอบแล้ว: คุยได้ ปุ่มเปิดร้านค้าได้ ลาก่อนปิดได้ ผู้เล่นเดินชน NPC แล้วหยุด; ไม่มี error
