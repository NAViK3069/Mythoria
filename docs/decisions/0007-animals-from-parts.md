# 0007 — สัตว์ในแผนที่ (แมว กระรอก นกกระจอก) ประกอบจากชิ้นส่วน

- สถานะ: Accepted
- วันที่: 2026-11-09

## บริบท
- อยากให้แผนที่ดูมีชีวิตชีวา: มีนกกระจอก กระรอก แมว ฯลฯ ตามแมพ
- แมวต้องมีท่าทางที่ควรมี: ยืน เดิน นั่ง นอน; สัตว์อื่นก็เช่นกัน
- เจ้าของเกมอยากให้ใช้วิธีแยกชิ้นส่วนแล้วประกอบ/ขยับเอง (แบบน้ำพุ) — ใช้เครื่องมืออย่างชาญฉลาด

## การตัดสินใจ
- **ภาพจาก PixelLab แล้วแยกชิ้นส่วนขยับเองในโค้ด** (ไม่ใช้แอนิเมชันที่ AI วาดทีละเฟรม ซึ่งมักสั่นไม่นิ่งที่ขนาดเล็ก)
  - เลือกภาพท่าหลักจากผู้สมัครหลายสิบภาพ: แมวยืน / นั่ง (18 px), แมวนอนขดตัว (16 px), กระรอก (16 px) → `assets/world/animals/`
  - ขนาดตัวกำหนดจากขนาดผืนภาพ (เครื่องมือวาดเต็มผืนเสมอ): แมวสูงราวครึ่งหนึ่งของฮีโร่ 32 px
  - นกกระจอกเล็กเกินกว่าผืนภาพเล็กสุดของเครื่องมือ (16 px) จึงวาดเองเป็นตารางพิกเซล 9×9 ด้วยสีจากนกที่ generate
- **`tools/animal_parts.py`** ตัดชิ้นส่วนด้วยกรอบที่วัดจากภาพ → `public/assets/world/animals.png/json` (atlas)
  - ทุกชิ้นอยู่บนผืนภาพเดิมของมัน → ทุกชิ้นใช้จุดอ้างอิงเดียวกัน (กลางล่าง) การขยับ = เลื่อนชิ้นทีละพิกเซลเต็ม
  - แมวยืน: ตัว (มีหัวอยู่ใต้ด้วย หัวขยับแล้วไม่เป็นรู), หัว, ขา 4 ข้าง, หาง 5 ระดับการแกว่ง (เฉือนทีละแถว: ปลายขยับ โคนอยู่กับที่)
  - แมวนั่ง: ตัว, หัว, หัวหลับตา (กะพริบ), หาง 5 ระดับ; แมวนอน: 2 จังหวะหายใจ (ครึ่งบนยกขึ้น 1 px)
  - กระรอก: ตัว หัว ขาหน้า ขาหลัง หาง; ท่านั่งชันตัว = ส่วนหน้าเอียงยกขึ้น (คอลัมน์ยิ่งไปข้างหน้ายิ่งยกสูง) + ท่าแทะ
  - นกกระจอก: ยืน จิก กระโดด กระพือปีก 3 จังหวะ
  - **สีขนแมว 5 แบบ** (ส้ม เทา ดำ ครีม น้ำตาล): ทุกภาพของแมวถูกจัดลงไล่สีขนชุดเดียวกันตามความสว่างของแต่ละพิกเซลก่อน แล้วค่อยเปลี่ยนสี ท่าต่างๆ ของแมวตัวเดียวกันจึงสีตรงกัน
  - atlas ผ่านการปรับโทนสีเดียวกับภาพแมพ (`gradedCopy`) ตอนโหลด
- **พฤติกรรม** (`world/Animals.ts`):
  - แมว: เดินเล่นใกล้ที่ของมัน (ขาเดินเป็นคู่ทแยง ยกขาตอนก้าว ตัวกระเพื่อม หางแกว่ง), ยืน (เงยหน้าบ้าง), นั่ง (สะบัดหางเป็นช่วงๆ กะพริบตา), นอนขดหายใจมี "z" ลอย; หันมามองเมื่อผู้เล่นเข้าใกล้, เดินเลี่ยงหนีถ้าเดินชน, ตื่นเมื่อเดินมาใกล้มาก
  - กระรอก: อยู่กับต้นไม้ของมัน กระโดดไปมา (ขาเหยียดตอนลอย หางตามหลัง) นั่งแทะ สะบัดหาง; ผู้เล่นเข้าใกล้ → วิ่งไปที่ต้นไม้ ไต่ขึ้นลำต้นหายเข้าพุ่มไม้ แล้วค่อยไต่ลงมาเมื่อผู้เล่นไปไกลแล้ว
  - นกกระจอก: เป็นฝูง 3–5 ตัวบนทางเดิน กระโดด จิกพื้น หันไปมา; ผู้เล่นเข้าใกล้ (หรือนานๆ ครั้ง) → บินขึ้นพร้อมกันไปลงที่อื่นที่ห่างจากผู้เล่น มีเงาบนพื้น
  - ที่อยู่: เมือง — แมวหน้าประตูร้านและข้างม้านั่ง นกบนถนนหินปู กระรอกตามต้นไม้ในสวน; ทุ่งหญ้า — แมวที่หมู่บ้านและแคมป์ นกบนทางเดิน กระรอกตามต้นไม้
  - สัตว์ไม่เดินทะลุสิ่งของ (เช็ค hitbox ของวัตถุ) และไม่ลงน้ำ; สัตว์นอกจออัปเดตน้อยที่สุด
- **ลำดับเลเยอร์** (`MeadowView.depthFor`): สัตว์เรียงตามเท้า แต่ตรงที่ทับภาพวัตถุ จะเทียบกับขอบหน้า hitbox ของวัตถุ ณ ตำแหน่ง x ของสัตว์ (แบบเดียวกับผู้เล่น)
  - สัตว์ข้างม้านั่งเฉียง มุมบ้าน หรือข้างน้ำพุ จึงอยู่หน้า/หลังถูกต้อง และเมื่ออยู่หน้าวัตถุก็อยู่หน้าสิ่งที่วาดตามวัตถุนั้นด้วย (เช่นน้ำของน้ำพุ)
  - นกที่บินอยู่เรียงตามจุดบนพื้นใต้ตัว
  - ทดสอบ: ก่อนแก้เรียงผิด 226 ครั้งในเมือง (นกข้างน้ำพุถูกน้ำพุทับ) และ 45 ครั้งในทุ่งหญ้า (ต้นไม้ บ้าน) — หลังแก้ 0

## ผลที่ตามมา
- เพิ่มสัตว์ใหม่ได้ด้วยวิธีเดียวกัน: generate ท่าหลัก → เพิ่มกรอบชิ้นส่วนใน `tools/animal_parts.py` → เขียนพฤติกรรม
- ทดสอบแล้ว: นกบินหนีและลงที่ใหม่, แมวหันมอง/เดินหลบ/ตื่น, กระรอกขึ้นต้นไม้แล้วลงมา; ไม่มี error; texture ไม่สะสมเมื่อเดินทางข้ามแผนที่
- ใช้เวลาอัปเดตราว 0.04 ms ต่อเฟรม
