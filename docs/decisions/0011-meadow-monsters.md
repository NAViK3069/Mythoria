# 0011 — มอนสเตอร์ในทุ่งหญ้า (5 ชนิด + มินิบอส)

- สถานะ: Accepted
- วันที่: 2026-11-09

## บริบท
- เจ้าของเกมขอมอนสเตอร์ในแผนที่ทุ่งหญ้า 5 ชนิด แต่ละชนิดมีมินิบอสของตัวเอง (เช่น สไลม์ / สไลม์มินิบอส, ต้นไม้ / ต้นไม้มินิบอส)
- ยังไม่มีระบบต่อสู้ (Phase 1: Encounter / combat / Battle Scene ยังไม่ทำ)

## การตัดสินใจ
- **ข้อมูลใน `packages/game-data/src/monsters.ts`**: `MONSTERS` (ค่าสถานะ 11 ค่า, ตีปกติ, สกิลแบบ LineRanger_TurnBased แต่ใช้ "ทุก n เทิร์น" แทนพลังงานทีม, ธาตุ, เลเวล, ตัวไหนเป็นมินิบอส) และ `MAP_SPAWNS` (แต่ละแมพมีชนิดไหน กี่ตัว อยู่ถิ่นแบบไหน เวลาเกิดใหม่) — ร่างแรก รอเจ้าของเกมแก้ (`docs/game-design/monsters.md`)
- **ภาพ**: ตัวนิ่งจาก PixelLab `create_image_pro` (ตัวธรรมดา 32px, มินิบอส 48px, 64/25 แบบ เลือก 1) กลับด้านให้หันขวาทุกตัว; ท่าในที่จาก PixelLab `animate_image` (idle ทุกตัว, เดินสำหรับตัวที่มีขา, กระพือปีกสำหรับผึ้ง — 1 generation ต่อท่า)
  - เฟรมที่ AI วาดเพี้ยน (เขาพลิก จุดบนหมวกเปลี่ยน) ไม่เอา: `tools/monster_parts.py` เลือกเฟรมที่เข้ากัน (`ANIMS`) และเล่น idle แบบไป-กลับ จึงไม่กระตุกตอนวนรอบ
  - การเคลื่อนที่บนพื้นทำในโค้ด: สไลม์/กระต่าย กระโดดเป็นโค้ง (ยุบตอนลง ยืดตอนลอย), เห็ด/ต้นกล้า เดินด้วยท่าเดิน, ผึ้งบินลอยมีเงาที่พื้น
- **วางในแมพ** (`world/Monsters.ts`): สุ่มแบบ seed ตามถิ่น — ริมน้ำ / หญ้าโล่ง / ร่มเงา (ดงเห็ด ตอ ขอนไม้) / ใต้ต้นไม้ / ดงดอกไม้; ไม่เกิดใกล้จุดเกิด ค่าย หมู่บ้าน แท่นวาป; มินิบอสเลือกถิ่นที่ไกลจากจุดเกิดที่สุดและห่างกัน ≥ 420px
- **ยังไม่ต่อสู้**: เดินไปใกล้/แตะ → การ์ดมอนสเตอร์ (`ui/panels/monster.ts`) ปุ่มต่อสู้ปิดไว้ — Encounter จะเริ่มจากจุดนี้
- มอนสเตอร์นอกจอหยุดนิ่ง (แบบเดียวกับสัตว์) และไม่ขวางทางเดิน

## ผลที่ตามมา
- เพิ่มมอนสเตอร์: เจนภาพ → ใส่ `assets/monsters/<look>.png` + เจนท่า → เพิ่มใน `ANIMS` ของ `tools/monster_parts.py` → เพิ่มใน `MONSTERS`/`MAP_SPAWNS` (ถ้าเป็นแบบเคลื่อนที่ใหม่ เพิ่มใน `MOVES` ของ `Monsters.ts`)
- ใช้ PixelLab ~114 generations (ภาพ 10 ชุด + ท่า 14)
