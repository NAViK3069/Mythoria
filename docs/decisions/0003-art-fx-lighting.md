# 0003 — งานภาพแมพ, เอฟเฟกต์ และแสง

- สถานะ: Accepted
- วันที่: 2026-11-08

## บริบท
ต้องการแมพสวยแนวเดียวกับเกม pixel top-down คุณภาพสูง เล่นลื่น 60 FPS บนเว็บ มีเอฟเฟกต์แฟนตาซีอลังการ และตัวละครขยับนุ่มนวล

## การตัดสินใจ
- **ภาพแมพจาก PixelLab** (แผน Pro ของผู้สร้าง)
  - Tileset แบบ Wang 16px โหมด pro 3 ชุดที่ต่อกันได้: น้ำ↔หญ้า (ตลิ่งยก), หญ้า↔ทางดิน, หญ้า↔หญ้าเข้ม
  - ต้นไม้, พุ่มไม้, ซากกำแพง/เสา, หิน, หีบ, ถัง, ลัง, เห็ด, ตอไม้, ใบบัว, ดอกไม้/ใบหญ้า — สร้างด้วย Create Image (Pro) แล้วคัดเลือกชิ้นที่ดีที่สุด
  - ไฟล์ต้นฉบับเก็บที่ `assets/world/meadow/` แล้ว `tools/build_meadow_assets.py` จะแพ็กเป็น atlas + ตาราง autotile
- **เอฟเฟกต์จาก pixelfx** (MIT, ติดตั้งจาก GitHub ล็อกไว้ที่ commit) — `FxSprite` แปลงเอฟเฟกต์เป็น texture ของ Phaser และหยุดคำนวณเมื่ออยู่นอกจอ
- **เงา**: แดดสูงเยื้องซ้ายบน — เงาคือรูปทรงของวัตถุนั้นเองกดแบนลงพื้นใต้ตัว เลื่อนไปขวาล่างเล็กน้อย (ไม่พลิกภาพ) + เงาสัมผัสพื้นเข้มๆ ที่ฐาน เป็นพิกเซลคม เงาที่ซ้อนกันจะรวมเป็นผืนเดียว
- **แสงผูกกับด่าน ไม่ผูกกับจอ**: light map อบไว้ (ร่มเงาใต้ป่า + แดดอุ่นในลาน + แสงลอดใบไม้), เงาเมฆเลื่อนผ่าน, ประกายบนน้ำ, ละอองในอากาศ, ไฟกระถาง + point light กะพริบ
  - ไม่ใช้ vignette หรือแสงเฉียงที่ติดกับจอ — แสงเฉียง (god rays) เก็บไว้ใช้ในฉากต่อสู้ turn-based
- **Hitbox**: อ่านจากพิกเซลจริงของภาพ — ฐานวัตถุเป็นสี่เหลี่ยมมุมมน กว้างเท่าส่วนทึบที่ฐานภาพ ลึกเท่าหน้าบนในมุม 3/4 (กล่อง/ถัง/หิน ≈ ครึ่งความสูง, กำแพงเป็นแผ่น, ต้นไม้แค่ลำต้น); เท้าผู้เล่นกว้างเท่าลำตัว (12×6 px); ของที่วางกระจายต้องห่างกันพอเดินผ่านจริง ไม่มีช่องแคบให้แทรกครึ่งตัว
- **การวางวัตถุ**: ห้ามฐานของสิ่งใดอยู่ในภาพของสิ่งที่อยู่ด้านหน้า (ลำต้นทุกต้นต้องมองเห็น) และมีระยะห่างแบบวงรี
- **การซูม**: วาดที่ความละเอียดจริงของจอ (DPR สูงสุด 2) ซูมเป็นจำนวนเต็ม — เห็นแมพราว 540 px บนจอคอม/iPad, 360 px บนมือถือ
- **ตัวละครขยับแบบลื่น** (ไม่ snap ทีละพิกเซล): สปริง, เอียงตัว, หัวตามหลังตัว, มือลอยทั้งสองข้างอยู่หน้าตัว (`roundPixels: false`)

## ผลที่ตามมา
- พื้นและเงาอบเป็น texture ใหญ่ครั้งเดียว — วาดเร็ว ไม่มีรอยต่อ tile
- ต้องแนบ `THIRD_PARTY_NOTICES.txt` ไปกับเกม (ทำไว้ใน `apps/client/public/`)
- แสดงผล ~60 FPS ขึ้นไปบนเดสก์ท็อป; มือถือรุ่นเก่ายังต้องทดสอบจริง
