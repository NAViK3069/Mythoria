# 0013 — แผนที่ต่อสู้ของด่าน (arena) + หน้าจอต่อสู้แบบ LineRanger_TurnBased

- สถานะ: Accepted (แทนส่วน "สู้บนแมพตรงจุดที่เจอ" ของ ADR 0012)
- วันที่: 2026-11-09

## บริบท
- เจ้าของเกมขอ "แผนที่สำหรับต่อสู้ของด่านนี้" และหน้าจอต่อสู้ตามภาพตัวอย่างจาก LineRanger_TurnBased (TURN n/80 · เลือดรวมสองทีม + VS · ลำดับเทิร์นเป็นข้าวหลามตัดด้านซ้าย · AUTO / ความเร็ว · ธาตุ + แถบเลือด + เลเวลเหนือตัว · แถบล่าง: การ์ดตัวที่ถึงตา, ข้อมูล, ท่า 3 ช่อง, พลังงานเป็นช่องๆ)

## การตัดสินใจ
- **แผนที่ต่อสู้ = แผนที่เล็กของด่าน** สร้างด้วยโค้ดจากภาพชุดเดียวกับทุ่งหญ้า (`world/arenaMap.ts` → `buildArena`): ลานดินตรงกลางที่สองฝั่งยืน (เว้นว่าง), ศาลเจ้าเก่าพร้อมไฟวิญญาณและเสาหักด้านหลัง, กำแพงต้นไม้ด้านหลังและสองข้างจอ, บ่อน้ำมีใบบัวมุมหน้า, เห็ด/ตอไม้/ขอนไม้/ดอกไม้, หิ่งห้อย ผีเสื้อ — วาดด้วย `MeadowView` + `Ambience` ตัวเดียวกับแมพ (แสง เงา เมฆ น้ำ) จึงเข้ากับแมพเป๊ะ
  - ไม่ใช้ภาพพื้นหลังที่ AI วาดทั้งภาพ เพราะจะไม่เข้ากับแสงเงา/สเกลพิกเซลของแมพ และขยับไม่ได้
  - ด่านถัดไป: เขียน `buildArena` ของด่านนั้น (ภาพชุดของด่าน)
- **ฉากแยก** `scenes/BattleScene.ts`: กดต่อสู้ → กล้องแมพพุ่งเข้า + จางดำ → แมพ "หลับ" (`scene.sleep`) → ฉากต่อสู้จางเข้า → จบแล้วกลับ แมพตื่นที่เดิม (ไม่โหลดแมพใหม่)
  - texture ที่ view สร้าง (ground, shadows, clouds, ponds…) ตั้งชื่อนำหน้าด้วย `art/texPrefix.ts` — ฉากต่อสู้ใช้ `bt:` ไม่ทับของแมพที่หลับอยู่ และลบทิ้งเมื่อฉากปิด
  - กล้องซูมเลขเต็มให้ลานพอดีจอ (ราว 280×170 px, จอแนวตั้ง 230 กว้าง) ตัวละครใหญ่แบบเกมต้นแบบ
- **หน้าจอ** (`ui/battleHud.ts` + CSS ใน `ui.css`) จัดตามภาพตัวอย่าง แต่ภาพทั้งหมดเป็นของเราเอง (ไม่ใช้รูป UI ของเกมนั้น ซึ่งดูเหมือนมาจาก LINE Rangers):
  - ป้าย VS: โล่ทอง + ใบลอเรลจาก PixelLab (`assets/ui/battle/vs.png`) ตัวอักษร VS เขียนทับด้วยโค้ด
  - ไอคอนสกิลฮีโร่ 14 อัน จาก PixelLab (7 งาน × 64 แบบ เลือกตัวละ 2) `assets/ui/skills/<hero>_skill1|2.png`; ตีปกติใช้รูปอาวุธของฮีโร่; มอนสเตอร์ใช้ไอคอนธาตุ
  - ปุ่มท่า Z / X / C (และ 1 / 2 / 3), A = ออโต้, Space = ใส่เป้าที่ดีที่สุด, ⚙ = เมนู (หนี)
  - ตัวที่ถึงตามีวงแหวนทองใต้เท้า (Phaser)
  - จอแคบ/แนวตั้ง: ลำดับเทิร์นเป็นแถวแนวนอนใต้ TURN, แถบล่างซ้อนเป็นสองชั้น

## ผลที่ตามมา
- ใช้ PixelLab ~80 generations (ไอคอนสกิล 70 + ป้าย VS 10)
- เพิ่มฮีโร่ใหม่: ต้องมีไอคอนสกิล 2 อันใน `assets/ui/skills/` (และสำเนาใน `apps/client/public/assets/ui/skills/`)

## เพิ่มเติม: ทรานซิชันและความอลังการ (เจ้าของเกมขอ "UI แบบเกมคุณภาพ" + ทรานซิชันแบบ slash-wipe)
- **ทรานซิชัน** — เจ้าของเกมขอให้ทำเองแบบของเรา (ไม่ใช้ของคนอื่น) แต่คล้าย slash-wipe: **"Mythoria cut"** `fx/effects/battleCut.ts` วาดด้วย engine ของเราเอง (`fx/surface.ts`) ทุกเฟรมบนแคนวาสพิกเซลกว้าง ~400 px สูงตามสัดส่วนจอ (ไม่โดนตัด) ขยายเต็มจอ — (1) ใบมีด 3 เล่มฟันเข้ามาทีละแถบ บน←ซ้าย กลาง←ขวา ล่าง←ซ้าย ขอบร้อนขาว→ทอง→มืด ประกายไฟกระเด็น (2) ปิดจอสนิท รอยต่อเรืองทอง ตราเพชรทองหมุนกางกลางจอพร้อมแสงกากบาท — ตอนนี้สลับฉากข้างใต้ (0.47 วิ) (3) รอยฟันขาวพุ่งออกจากตราตามแนวเฉียง จอวาบ แล้วผ้าคลุมแยกเป็นสองซีกเลื่อนออก ขอบเรืองฟ้าน้ำแข็ง/ทอง ประกายพุ่งจากรอยแยก — ใช้ทั้งเข้าและออกจากการต่อสู้ (`ui/transition.ts`)
- **ในการต่อสู้**: ป้ายเปิดฉาก "เริ่มต่อสู้!" (หน้าทั้งสองทีมพุ่งเข้า + VS กระแทก) · cut-in ตอนใช้สกิล (แถบเฉียงพาดจอ รูปตัวละครใหญ่ เส้นความเร็ว ชื่อสกิล สีตามธาตุ — ฮีโร่จากซ้าย มอนสเตอร์จากขวา) · แถบเลือดมีรอยดาเมจค้างแล้วค่อยลด · คริ/ตีหนัก = จอสั่น + หยุดภาพแวบหนึ่ง (hit-stop) · แถบล่างเด้งเข้าทุกเทิร์น ไอคอนท่าเรืองตอนถึงตาเรา · หน้าผล: แสงหมุน ริบบิ้น ดาว 1–3 (รอดทั้งทีม 3 / เกินครึ่ง 2 / อื่นๆ 1) และ MVP (ดาเมจมากสุด)
- **ทุกหน้าจอ** (ชั้น polish ท้าย `ui.css`): ขอบมืดแบบภาพยนตร์บนแมพ, แสงทองกวาดผ่านแผง HUD เป็นระยะ, ปุ่มเรืองเมื่อชี้และยุบเมื่อกด, ปุ่มโหมดเล่นหายใจเรือง, หัวหน้าต่างไล่สีทอง, ปุ่มปิดหมุน, การ์ดยกตัวเมื่อชี้, ของในหน้าต่างค่อยๆ เข้าทีละชิ้น — ปิดแอนิเมชันเมื่อเครื่องตั้ง reduced motion
