# 0015 — คลิกเพื่อเดิน: หาทางอ้อมสิ่งกีดขวาง (A* บนตารางเดินได้)

- สถานะ: Accepted
- วันที่: 2026-11-10

## บริบท
- เดิมคลิก/แตะพื้นแล้วตัวละครเดินเป็นเส้นตรงไปหาจุดนั้น เจอต้นไม้ บ้าน บ่อน้ำ รั้ว ก็ไถลไปตามขอบแล้วติด ไม่อ้อม — เจ้าของเกมบอกว่า "โง่"
- อยากให้คลิกตรงไหนก็หาทางอ้อมไปได้เอง (ต้นไม้ หิน บ้าน บ่อน้ำ กำแพง/รั้ว NPC น้ำพุ ฯลฯ) ถ้าจุดที่คลิกเดินเข้าไม่ได้ ให้ไปจุดที่ใกล้ที่สุดที่ไปถึงได้
- ต้องคงความรู้สึกเดิม: กดเมาส์ค้างเดินตามเคอร์เซอร์แบบ MOBA, ลูกศรบอกจุดหมาย, การเคลื่อนไหวนุ่ม (`roundPixels: false`), ปุ่มคีย์บอร์ด/จอยสติ๊กทำงานเหมือนเดิม และ 60 FPS ทั้งสองแมพ

## การตัดสินใจ
- **โมดูลใหม่ `world/pathfind.ts`** (`NavGrid`) สร้าง **ตารางเดินได้** ครั้งเดียวตอนโหลดแมพ (ใน `WorldScene.create` หลังรวม hitbox ของ NPC แล้ว)
  - ช่องละ 4 px (`NAV_CELL`) — ทุ่งหญ้า 512×368 ช่อง, เมือง 320×256 ช่อง; สร้างเสร็จใน ~20–35 ms (ใต้ม่านวาร์ป)
  - ช่องที่เดินไม่ได้ = **การทดสอบชุดเดียวกับที่การเดินใช้จริง**: `ground()` (ขอบแมพ + น้ำ `waterAt`) และ hitbox (polygon) ของวัตถุทุกชิ้นกับเท้ารูปวงรีของตัวละคร (`pushOut` — ย้ายจาก WorldScene มาไว้ที่นี่ใช้ร่วมกัน) เผื่อระยะเพิ่ม 1.5 px ไม่ให้เส้นทางเฉียดทุกลำต้น
  - พุ่มไม้ยังเดินทะลุได้เหมือนเดิม (ไม่อยู่ใน `feet`); มอนสเตอร์/สัตว์ไม่บังทาง (การเดินก็ไม่ชนมัน)
  - แบ่ง **พื้นที่ที่เชื่อมกัน** (flood fill) ไว้ล่วงหน้า → รู้ทันทีว่าจุดไหนไปถึงได้ ไม่ต้องค้นทั้งแมพเพื่อพบว่าไปไม่ได้
- **ตอนคลิก** (`NavGrid.find`):
  - จุดที่คลิกอยู่ในสิ่งกีดขวาง/น้ำ หรืออยู่คนละพื้นที่ → หาช่องว่างที่ใกล้จุดนั้นที่สุดในพื้นที่เดียวกับตัวละคร (ค้นเป็นวงออกไป) แล้วไปที่นั่นแทน — ลูกศรตกตรงที่จะไปถึงจริง (ข้างผนังบ้าน ริมบ่อ)
  - มองเห็นเป็นเส้นตรงได้เลย → เดินตรงไป ไม่ต้องค้น
  - ไม่งั้น **A\*** 8 ทิศ ห้ามตัดมุม (heuristic แบบ octile, heap แบบ typed array ใช้ซ้ำ) แล้ว **ดึงเส้นทางให้ตึง** (line-of-sight: จากแต่ละมุมไปไกลที่สุดที่ยังเห็นเป็นเส้นตรง) เหลือจุดเลี้ยวไม่กี่จุด
  - ใช้เวลาปกติ ~1 ms, ข้ามทั้งแมพทุ่งหญ้าแย่สุด ~17 ms
- **การเดินตามเส้นทาง** (`WorldScene.update`): เล็งไปจุดถัดไปด้วยความเร็วเต็ม ผ่านจุด (ใกล้กว่า 3 px) หรือมองเห็นจุดถัดไปแล้ว → ข้ามไปจุดถัดไป; ชะลอเฉพาะช่วงไม่กี่ px สุดท้ายของจุดหมายเหมือนเดิม การชน/ไถลตามขอบยังใช้ `move()` เดิม
  - เป้าหมายขยับ (กดเมาส์ค้าง, เดินไปหามอนสเตอร์ที่เดินไปมา) → คำนวณทางใหม่ไม่เกินทุก 0.2 วินาที และเฉพาะเมื่อเป้าขยับเกิน 1 ช่อง
  - ติดอยู่กับที่ (> 0.25 วินาที) → คำนวณทางใหม่ (สูงสุด 2 ครั้ง) แล้วค่อยยอมแพ้ (เดิมยอมแพ้ทันที)
  - กดปุ่มทิศ/ลากจอยสติ๊ก → ยกเลิกเส้นทาง (เหมือนเดิม)
- ไม่แสดงเส้นทางในเกม (มีแค่ลูกศรจุดหมาย) — `?hitboxes` ใน URL วาดช่องที่เดินไม่ได้ (สีฟ้าจาง) และเส้นทางที่กำลังเดิน (สีเหลือง) ไว้ตรวจ

## ผลที่ตามมา
- คลิกหลังต้นไม้ ข้ามบ่อน้ำ เข้าไปในซากกำแพง หรือบนบ้าน/น้ำพุ ตัวละครเดินอ้อมไปถูกที่ทั้งในเมืองและทุ่งหญ้า
- ตารางสร้างจาก hitbox ชุดเดียวกับการชน → เพิ่มของ/ภาพใหม่แล้วรัน `tools/hitboxes.py` ตามเดิม ทางเดินอัปเดตเอง ไม่ต้องวาดแผนที่ทางเดินแยก
- ถ้าวันหลังมีสิ่งกีดขวางที่ขยับได้ (NPC เดินไปมา ประตูเปิดปิด) ต้องอัปเดตช่องในตาราง (หรือพึ่งการคำนวณใหม่ตอนติด)
- ออนไลน์ภายหลัง: เซิร์ฟเวอร์ใช้ `NavGrid` เดียวกันตรวจการเดินได้ (เป็น TS ล้วน ไม่พึ่ง Phaser)
