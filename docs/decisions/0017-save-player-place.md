# 0017 — จำตำแหน่งผู้เล่น: รีเฟรช/ปิดแล้วกลับมาที่เดิม

- สถานะ: Accepted
- วันที่: 2026-11-10

## บริบท
- เดิมเกมเริ่มที่เมือง (ล็อบบี้) จุดเกิดเดิมทุกครั้ง กด F5 / ปิดแล้วเปิดใหม่ก็กลับไปจุดเกิด แม้จะเดินไปไกลในทุ่งหญ้าแล้ว
- เจ้าของเกมต้องการ: อยู่ตรงไหนของแมพตอนรีเฟรช/กด F5/ออกแล้วกลับมา ต้องอยู่ที่เดิม (แมพเดิม จุดเดิม หันทางเดิม) — ยกเว้นแมพนั้นถูกลบหรือมีปัญหา ให้ทิ้งตำแหน่งที่เซฟไว้แล้วไปเริ่มที่เมือง
- ข้อมูลผู้เล่นทั้งหมดอยู่ใน `ui/store.ts` (เก็บใน localStorage `mythoria.player.v1`) ซึ่งวันหลังจะย้ายไป `GameService`

## การตัดสินใจ
- **เก็บไว้กับข้อมูลผู้เล่น**: `player.place` (`SavedPlace`) = `{ v: 1, map, x, y, facing, at }` ใน `ui/store.ts` — มีเลขเวอร์ชัน `v` ของตัวเอง รูปแบบที่โค้ดไม่รู้จัก (เวอร์ชันอื่น ตัวเลขเสีย) ถูกทิ้งตอนโหลด; ย้ายไป GameService พร้อมข้อมูลอื่น
  - `savePlace()` เขียนทันทีโดยไม่เรียก listener (ไม่มีอะไรต้องวาดใหม่), `clearPlace()`, `flushSave()` (เขียนที่ค้างอยู่ตอนหน้าเว็บจะปิด), `wipeSave()` (ปุ่ม "ล้างข้อมูลในเครื่อง" — กันไม่ให้ตอนปิดหน้าเขียนข้อมูลกลับมาอีก)
- **เซฟเมื่อไร** (`WorldScene.keepPlace`):
  - ระหว่างเดิน ไม่เกินทุก 1 วินาที (`SAVE_EVERY`), หยุดเดิน/หันหน้า → เซฟทันที
  - `pagehide` และ `visibilitychange` → hidden (รีเฟรช ปิดแท็บ สลับแอปบนมือถือ)
  - ก่อนเข้าต่อสู้ (จุดที่เริ่มสู้), มาถึงแมพใหม่ด้วยวาร์ป (จุดลงของแผ่นวาร์ปปลายทาง — เซฟไว้ใต้ม่าน)
  - **ไม่เซฟ** ระหว่างวาร์ป/ม่านเดินทาง (`warps.busy`) และระหว่างต่อสู้ (แมพหลับ) → รีเฟรชกลางการต่อสู้ = กลับมาบนแมพตรงจุดที่เริ่มสู้ (ไม่ต่อการต่อสู้)
- **ตอนเริ่มเกม** (`WorldScene.create` ไม่มี `data.map` = ไม่ใช่การเดินทาง) ใช้ตำแหน่งที่เซฟเมื่อ:
  - id แมพยังอยู่ใน `world/maps.ts` `MAPS` — ไม่อยู่ → ลบทิ้ง เริ่มที่เมือง
  - จุดอยู่ในแมพ และเท้ายืนได้ด้วย **การชนชุดเดียวกับการเดิน** (`ground()` + hitbox ทุกชิ้นด้วย `pushOut`) และอยู่บนพื้นที่ที่เชื่อมกับจุดเกิดของแมพ (`NavGrid.regionAt` — ไม่ติดอยู่ในซอกที่ออกไม่ได้)
  - ถ้าโดนบังนิดหน่อย (ภาพ/ของย้ายมาทับ) → ขยับไปช่องว่างที่ใกล้ที่สุดในพื้นที่เดียวกันไม่เกิน 8 ช่อง (32 px, `NavGrid.nearestFree`) แล้วเซฟจุดใหม่
  - ไม่งั้น → ลบทิ้ง แล้วเริ่มใหม่ที่จุดเกิดของเมือง (ถ้าอยู่แมพอื่นก็ `scene.restart` ไปเมือง)
- **ป้ายชื่อพื้นที่** (หนึ่งครั้งต่อแมพ ตอนมาถึง): กลับมาที่เดิมภายใน 10 นาที (`ANNOUNCE_AFTER`) ถือว่าแค่รีเฟรช ไม่โชว์; นานกว่านั้นโชว์ให้รู้ว่าอยู่ไหน กล้อง/มินิแมพ/วาร์ปทำงานเหมือนมาถึงปกติ

## ผลที่ตามมา
- F5 / ปิดแล้วเปิด / กลับมาวันหลัง → แมพเดิม จุดเดิม หันทางเดิม ทั้งเมืองและทุ่งหญ้า
- ลบแมพ เปลี่ยนชื่อ id แมพ หรือย้ายภาพจนจุดเดิมเดินไม่ได้ → ไม่พัง กลับเมืองเอง
- แก้ localStorage ด้วยมือตอนเกมเปิดอยู่จะถูกทับตอนปิดหน้า (เกมเซฟตำแหน่งปัจจุบันตอน `pagehide`) — จะทดสอบค่าเสียต้องหยุดฉาก World ก่อน
- ออนไลน์ภายหลัง: เซิร์ฟเวอร์เก็บ `place` กับข้อมูลผู้เล่น และตรวจด้วย `NavGrid` ชุดเดียวกันได้ (กันวาร์ปโกง)
