# 0010 — ระบบฮีโร่ชุดแรก และฮีโร่ Rare เริ่มต้น 7 ตัว

- สถานะ: Accepted
- วันที่: 2026-11-09

## บริบท
- เจ้าของเกมกำหนด: 6 อาชีพ, ระดับ Rare < Epic < Legend < Mythic, ค่าสถานะ 11 ค่า, อุปกรณ์ 4 ช่อง (อาวุธ เกราะ ของประดับ คัมภีร์), ดาว 5 ดาวด้วยตัวซ้ำ ปลดล็อกพรสวรรค์ C0–C5 (ระดับต่ำใช้ตัวซ้ำเยอะ, Mythic 1 ตัวต่อขั้น)
- ขอให้ Claude ออกแบบฮีโร่ Rare เริ่มต้น 7 ตัว: แทงค์ นักรบ นักฆ่า นักยิง นักเวท ซัพพอร์ต 2
- กติกาการต่อสู้ยกมาจาก LineRanger_TurnBased (เกมเดิมของเจ้าของ) ซึ่งมีตำแหน่ง 6 แบบตรงกันอยู่แล้ว

## การตัดสินใจ
- **ข้อมูลใน `packages/game-data`**: `heroBasics.ts` (อาชีพ + ความสามารถประจำอาชีพจาก `roleTraits.ts` ของ LineRanger_TurnBased, ระดับ + ตัวซ้ำต่อดาว, ค่าสถานะ, ช่องอุปกรณ์, รูปแบบสกิล) และ `heroes.ts` (ฮีโร่)
  - สกิลเขียนแบบเดียวกับ LineRanger_TurnBased (พลังงานทีม, เป้า, รายการผล) เพื่อยกระบบต่อสู้มาใช้ได้ตรงๆ ภายหลัง
  - ตัวคูณธาตุ ×1.5 / ×0.5 ใช้ค่าจาก LineRanger_TurnBased
  - ค่าสถานะเริ่มต้นตั้งต่ำกว่าเรนเจอร์ตำแหน่งเดียวกันในเกมนั้นเล็กน้อย (Rare)
- **ฮีโร่ 7 ตัวเป็นร่างแรก** (ชื่อ หน้าตา สกิล พรสวรรค์ ตัวเลข) — `docs/game-design/heroes.md`
- **หน้าตา** (แก้ครั้งที่ 3 — โมเดลเดียวกับ NPC):
  - ครั้งแรก: หัวโล้น + inpaint ทรงผม + ชุดเป็นตารางพิกเซลที่วาดเอง → เจ้าของเกมว่าหยาบ ไม่เท่
  - ครั้งที่ 2: เจนตัว chibi ทั้งตัวจาก PixelLab แล้วตัดเป็นชิ้น → สัดส่วน/หน้าไม่ใช่โมเดลเรา; เจ้าของเกมให้กลับมาใช้โมเดลแบบ NPC แต่เปลี่ยนชุดให้เป็นฮีโร่
  - **ตอนนี้**: สร้างแบบ NPC ทุกอย่าง — ร่างเปล่าของตัวละครหลัก (หัวโล้น หน้าเดิม ตัว ขา) แล้ว inpaint ด้วย PixelLab ครั้งเดียวต่อตัว: บริเวณผม/หมวก (หน้าไม่ถูกแตะ; ปิ๊ปเป็นหุ่นยนต์ inpaint ทั้งหัว) + ชุดในบล็อกลำตัว → ได้หมวก/ชุดที่ละเอียดกว่าตารางที่วาดเอง แต่หัว หน้า ตัว ขา เป็นโมเดลเดียวกับตัวหลักและ NPC
  - **ไม่มีแขน** (มือลอยคือแขน) · **ขาเป็นของตัวละครหลัก** ย้อมสีรองเท้า
  - อาวุธเจนจาก PixelLab (24×24, 64 แบบ เลือก 1) — จุดที่มือจับคำนวณจากภาพ; ในภาพยืนมือที่ถืออาวุธยื่นออกข้างตัว และอาวุธวาด**ทับหัว**
  - หน้า (การ์ดรายชื่อ) ครอบจากหัวและไหล่ ไม่มีมือ/อาวุธ
- **ไอคอนอาชีพ** 6 อัน จาก PixelLab (64 แบบ เลือก 6) เข้าชุดกับไอคอนเดิม
- **UI**: รายชื่อฮีโร่ (กรอง อาชีพ/ระดับ/ธาตุ/เผ่า) + หน้าฮีโร่; ผู้เล่นได้ฮีโร่เริ่มต้น 7 ตัว (ผู้เล่นเดิมที่ยังไม่มีก็ได้)

## ผลที่ตามมา
- เพิ่มฮีโร่ใหม่: inpaint ร่างเปล่า 1 ครั้ง (ผม/หมวก + ชุด) → เพิ่มแถวใน `HEROES` ของ `tools/hero_parts.py` (สีตา รองเท้า อาวุธ; ดูด้วย `--preview`) → เพิ่มข้อมูลใน `heroes.ts`
- ใช้ PixelLab ไป ~55 generations ครั้งแรก + ~160 ครั้งที่ 2 (ตัว chibi + อาวุธ 8) + 35 ครั้งที่ 3 (inpaint 7 ตัว)
- ยังไม่มี: การเติบโตตามเลเวล, ไอเทมอุปกรณ์, การเพิ่มดาวจริง (มีข้อมูลรองรับแล้ว), ระบบต่อสู้
