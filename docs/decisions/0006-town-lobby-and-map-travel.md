# 0006 — เมืองหลัก (ล็อบบี้) และการเดินทางข้ามแผนที่

- สถานะ: Accepted
- วันที่: 2026-11-09

## บริบท
- ต้องการเมืองหลักแบบเกมทั่วไป: อยู่กลางเมืองที่มีน้ำพุตรงกลาง มีร้านค้าและอาคารต่างๆ
- เป็นเมืองแฟนตาซีที่ไม่ยุคเก่ามาก (ล้ำกว่านิดหน่อย) สไตล์ภาพเดียวกับแผนที่ปัจจุบัน
- แผนที่ทุ่งหญ้าเดิมคือแผนที่เลเวล 1
- น้ำพุและ VFX ให้ลื่นไหลระดับเดียวกับตัวอย่างจาก pixelfx.io (water/fountain) แต่เป็นของเราเอง

## การตัดสินใจ
- **หลายแผนที่**: `world/maps.ts` เก็บรายการแผนที่ (`town` = เมืองหลัก/ล็อบบี้ — เกมเริ่มที่นี่, `meadow` = ทุ่งหญ้า Lv.1)
  - แต่ละแผนที่สร้างจากฟังก์ชันของมันเอง (`buildTown`, `buildMeadow`) เป็นโครงสร้างเดียวกัน (`MeadowMap`) ซึ่งรู้ขนาดของตัวเอง (`cols`/`rows`) และรู้ว่าพื้นปูใช้ tileset ไหน (`paved`: ทางดิน / หินปู)
  - ย้ายแผนที่ = `WorldScene` เริ่มใหม่บนแผนที่นั้น
    - ม่านเวทเป็นตัวเดียวทั้งเกม จึงค้างคลุมจอข้ามการเริ่มใหม่ได้
    - ฉากใหม่ "ลงจอด" ที่แท่นปลายทางตอนม่านเปิด (`Warps.arrive`)
  - texture ของแผนที่ก่อนหน้าถูกล้างทุกครั้งที่เริ่มแผนที่ใหม่ (เก็บไว้แค่ภาพที่โหลดตอนบูต) จึงไม่สะสมในหน่วยความจำ
- **หน้าต่างแท่นวาป**: ส่วนบนเป็น "เดินทางไปแผนที่อื่น" (จากทุ่งหญ้า: กลับเมือง + แผนที่ถัดไปที่ยังล็อก; จากเมือง: ทุ่งหญ้า Lv.1) ส่วนล่างเป็นแท่นอื่นในแผนที่เดียวกัน
- **เมืองหลัก** (`world/townMap.ts`, 80×64 ช่อง):
  - จัตุรัสหินปูทรงกลมพร้อมน้ำพุใหญ่ตรงกลาง ม้านั่ง โคมคริสตัล 8 ต้นรอบจัตุรัส แผงตลาด กระถางดอกไม้
  - ฝั่งเหนือ: หอกิลด์ (บันไดหน้าขึ้นถึงประตูได้), ร้านค้าทั่วไป, วิหารอัญเชิญ (คริสตัลเรืองแสง), กระดานเควส
  - ตะวันตก/ตะวันออก: ร้านยาวิเศษ, บ้าน
  - ใต้: โรงเตี๊ยม, โรงตีเหล็ก (เตาหลอมมีไฟ)
  - บ้านและสวนรอบนอก ป่ารอบขอบ ถนน 4 ทาง — ถนนใต้สุดคือประตูเมืองที่มีแท่นวาปไปทุ่งหญ้า
  - ชื่อสถานที่เป็นคำบรรยายชั่วคราว รอเจ้าของเกมตั้งชื่อจริง
- **ประตู/กระดานใช้งานได้**: เดินไปหน้าประตูแล้วปุ่มทองขึ้น (หรือกด E / Enter) เพื่อเปิดหน้าต่างที่มีอยู่แล้ว
  - ร้านค้าทั่วไปและร้านยา → ร้านค้า
  - กิลด์ → กิลด์
  - วิหาร → ซัมม่อน
  - กระดานเควส → เควส
  - โรงเตี๊ยมและโรงตีเหล็ก → "เร็วๆ นี้" (ยังไม่มีระบบ รอเจ้าของเกมกำหนด)
- **ภาพจาก PixelLab** (~125 generations) สไตล์เดียวกับของเดิม เก็บใน `assets/world/meadow/town_*` ชื่อขึ้นต้น `t_`:
  - อาคาร 9 หลัง
  - อ่างน้ำพุ (แห้ง — น้ำวาดเองด้วยโค้ด)
  - ของตกแต่งจัตุรัส 13 ชิ้น และของชิ้นเล็กขนาดจริง 32 ชิ้น
  - tileset หญ้า↔หินปูต่อกับหญ้าเดิมพอดี (ใช้ base tile เดียวกัน)
- **Hitbox** ของอาคาร/ของในเมืองทำแบบเดียวกับแผนที่เดิม (`tools/hitboxes.py`): อาคารหน้าตรงเป็นแนวกำแพง, อาคารเข้ามุมเป็นข้าวหลามตัด, ของกลมเป็นวงรี, เสาเป็นแค่เสา
- **VFX ของเราเอง** (`fx/effects/water.ts`, เอนจิน `fx/surface.ts`):
  - **น้ำพุ**: น้ำในอ่างล่างและอ่างบน มีแสงลายน้ำเคลื่อนไหว
    - สายน้ำพุ่งจากยอดรูปปั้นเป็นเสาพร้อมมงกุฎละอองน้ำ หยดน้ำโค้งตกลงอ่างบน
    - อ่างบนล้นเป็นม่านน้ำรอบวงตกลงอ่างล่าง มีแถบแสงไหลลงตามม่าน ครึ่งหลังอยู่หลังเสา
    - หยดน้ำกระเด็นและฟองตรงจุดน้ำตก ระลอกคลื่นแผ่ออก ละอองหมอก ประกายบนผิวน้ำ — วนลูปไม่มีรอยต่อ
  - **ควันจากปล่องไฟ**: บ้าน โรงเตี๊ยม และโรงตีเหล็ก
  - **แสง**: โคมคริสตัลทุกต้น (แสงนุ่ม) และคริสตัลวิหาร

## ปรับแก้หลังเจ้าของเกมทดสอบ
- **ป้ายชื่อพื้นที่ขึ้นแค่ 1 ครั้งต่อแผนที่** (ชื่อแผนที่ตอนเข้า) — ไม่มีป้ายย่อยตามพื้นที่ในแผนที่แล้ว
- **เลเยอร์ตอนผู้เล่นอยู่ใกล้**: วัตถุที่อยู่ใกล้ผู้เล่นถูกเลื่อนลำดับเพียงเท่าที่จำเป็น (ไม่ขึ้นไปทับของที่อยู่หน้ามัน) — ธงหน้ากิลด์จึงไม่ถูกตัวกิลด์ทับตอนผู้เล่นยืนหน้ากิลด์
- **น้ำพุประกอบจากชิ้นส่วน** (แทนการวาดน้ำทับภาพทั้งภาพ): `tools/fountain_parts.py` วัดจากภาพ `t_fountain` → `world/fountain_parts.json`
  - วัดอัตโนมัติจากวงทองในภาพ: ผิวน้ำอ่างล่าง (ถึงวงทองด้านใน), ผิวน้ำอ่างบน, ขอบปากอ่างบน (จุดที่น้ำล้นแล้วตกลงมา)
  - เส้นขอบเสาและรูปปั้นอ่านจากภาพทีละแถว แล้วตัดเป็นชิ้น "เสา+อ่างบน" และ "รูปปั้น"
  - เส้นระดับน้ำ: ส่วนของเสา/รูปปั้นที่อยู่ใต้น้ำไม่วาดทับน้ำ แต่เห็นจางๆ ผ่านน้ำ มีฟองรอบจุดที่โผล่พ้นน้ำ
  - ลำดับการวาด (`fx/effects/water.ts`): อ่างแห้ง (ภาพเดิม) → น้ำอ่างล่าง → ม่านน้ำครึ่งหลัง → เสาและอ่างบน → น้ำอ่างบน → หยดน้ำด้านหลัง → รูปปั้น → ม่านน้ำครึ่งหน้า ละอองที่จุดตก สายน้ำพุ่งและหยดน้ำด้านหน้า
  - ม่านน้ำเริ่มที่ขอบปากอ่างบนพอดี และตกลงวงที่กว้างกว่าปากอ่างเล็กน้อยบนผิวน้ำอ่างล่าง
  - แก้ภาพน้ำพุแล้วให้รันสคริปต์นี้ใหม่ (`--preview out.png` ดูชิ้นส่วนทับภาพ)
- **ควันออกจากปากปล่องไฟ**: ตำแหน่งปากปล่องของแต่ละภาพวัดจากภาพจริง (โรงเตี๊ยม 2 ปล่อง, โรงตีเหล็ก, บ้าน 3 แบบ)
- **กลับภาพซ้าย-ขวาได้** (`Placed.flip`): ภาพ เงา hitbox มินิแมพ และเงาสะท้อนน้ำกลับตามกัน — กระดานเควสและแผงผลไม้หันหน้าเข้าหาจัตุรัส/น้ำพุ
- **จัตุรัสโล่งขึ้น**: เอากระถางที่บังกระดานเควส ลังและกระถางที่เบียดแผงร้าน และกระถางที่ชิดเสาโคมออก; แผงผ้าและร้านขนมปังขยับห่างจากเสาโคม

## ผลที่ตามมา
- เพิ่มแผนที่ใหม่ได้ด้วยการเขียนฟังก์ชันสร้างแผนที่ + เพิ่มใน `MAPS`
- ทดสอบแล้ว:
  - เดินชนวัตถุ 189 ชิ้นในเมืองไม่ทะลุ
  - ประตูทั้ง 7 และแท่นประตูเมืองเดินไปถึงได้
  - เดินทางเมือง → ทุ่งหญ้า → เมืองได้
  - จำนวน texture คงที่หลังเดินทางไปกลับ
