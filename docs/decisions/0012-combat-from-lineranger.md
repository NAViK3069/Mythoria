## บริบท
- เจ้าของเกมให้ "ก๊อประบบ TurnBased จากเกมเก่า" https://github.com/NAViK3069/LineRanger_TurnBased (กติกาต่อสู้ของ Mythoria มาจากเกมนั้นตั้งแต่แรก — CLAUDE.md)
- `packages/combat` ต้องเป็น TypeScript ล้วน seed RNG ไม่แตะ Phaser/DOM (รันบนเซิร์ฟเวอร์ได้ภายหลัง)
- แนวเกม: สำรวจแบบ AFK Journey, ต่อสู้แบบ Honkai: Star Rail

## การตัดสินใจ
- **ยก engine มาแทบทั้งไฟล์** (`battle.ts` → `packages/combat/src/battle.ts`, `ai.ts` → `ai.ts`, กฎย่อย → `rules.ts`, รูปแบบข้อมูล → `types.ts`) — กติกา ตัวเลข (DAMAGE_SCALE, เพดาน, ต่อเวลา, AV) และ AI เหมือนเดิมทุกอย่าง เพราะเกมเดิมจูนไว้แล้ว (จบราว 45 เทิร์น)
  - ที่เปลี่ยน: ธาตุใช้ `matchup` + `MATCHUP_DAMAGE` ของ game-data (ธาตุแรก) · ความสามารถตำแหน่งอ่านจาก `CLASSES` ของ game-data · ค่าสถานะ 11 ค่าของเรา map เข้า (ต้านสถานะ = Skill Resistance เดิม, ต้านการโจมตีสกิล = Skill Damage Resistance, เพิ่ม "ต้านการโจมตีปกติ" แบบเดียวกัน, Hit = 0) · มอนสเตอร์ใช้สกิล "ทุก n เทิร์น" แทนพลังงาน
  - `setup.ts` แปลงฮีโร่/มอนสเตอร์จาก game-data เป็นยูนิต + จัดแถวอัตโนมัติ
  - เทส vitest 9 ข้อ (seed เดิมผลเดิม, ลำดับตาม Speed, ธาตุ, พลังงาน, แถวหน้าบัง, ยั่วยุ, สกิลมอนสเตอร์ทุก n เทิร์น, บาเรีย/ดาเมจต่อเนื่อง, ฮีโร่เริ่มต้นชนะมินิบอส ≥ 8/10)
- **สู้บนแมพตรงจุดที่เจอ** (ไม่ใช่ฉากแยก): กล้องซูม +1 เข้ากลางสนามที่เลือกจากพื้นโล่งใกล้มอนสเตอร์ (ไม่ทับต้นไม้/บ้าน/น้ำ), ตัวหลักหลบไป, ฮีโร่ (โมเดลเดียวกับตัวหลัก ถืออาวุธ) ยืนซ้าย มอนสเตอร์ยืนขวา — ใช้ฉากที่มีอยู่แล้ว สวยและต่อเนื่องแบบ AFK Journey; โลกยังมีชีวิตรอบๆ (สัตว์ ผีเสื้อ แสง)
- **HUD เป็น HTML** (`ui/battleHud.ts`) แบบเดียวกับ UI อื่น: รางลำดับเทิร์น, พลังงาน, ปุ่มท่า (มีเป้า/ราคา/คูลดาวน์), แถบเลือด+โล่+สถานะเหนือตัว, ตัวเลขเด้ง, พรีวิวเลือดที่จะหายตอนชี้เป้า, ออโต้/×2/หนี, หน้าผล
- `MasterCharacter.setGear` ให้ฮีโร่ถืออาวุธในการต่อสู้ (ข้อมูลจับอาวุธ `world/heroGear.json` จาก `tools/hero_parts.py`)
- หน้าทีม: เลือกฮีโร่ 5 ตัวที่ลงสู้ (`player.team`)
