# 0018 — เลือดถาวรของฮีโร่ (ระหว่างการต่อสู้แต่ละครั้ง)

- สถานะ: Accepted
- วันที่: 2026-11-13

## บริบท
- เจ้าของเกมต้องการระบบแบบ Honkai: Star Rail: สู้จบเหลือเลือดเท่าไหร่ก็เท่านั้น ฮีลได้ในการต่อสู้หรือกินยานอกการต่อสู้; ล้มแล้วต้องใช้ยาชุบชีวิตหรือรอคูลดาวน์นาน
- เดิมทุกการต่อสู้เริ่มเลือดเต็ม
- และให้แสดงฮีโร่ 5 ตัวในทีมพร้อมเลือดบนแมพ ด้านซ้ายใต้กล่องเควส

## การตัดสินใจ
- **เก็บเป็นสัดส่วน** `OwnedHero.hp` (0..1, ไม่มี = เต็ม) + `downAt` (เวลาที่ล้ม) ใน `ui/store.ts` — สัดส่วน เพราะเลือดสูงสุดในการต่อสู้มีโบนัสแถวบวกเพิ่ม (ค่าดิบของฮีโร่ไม่ตรงกับในสนาม)
- **combat ยังบริสุทธิ์**: `UnitSetup.hpShare` (ใหม่, ไม่บังคับ) — `Battle.makeUnit` เริ่มเลือดที่ `max * hpShare` (อย่างน้อย 1); `heroTeam(ids, level, hpOf)` ใส่ให้ ไม่มีอะไรอื่นในเอนจินเปลี่ยน
- **เข้า/ออกการต่อสู้** (`BattleScene`): ส่ง `fitTeam(player.team)` (ตัดตัวที่ล้มออก) และสำรองเฉพาะที่ไม่ล้ม; `BattleStage.finish` ส่งเลือดที่เหลือของฮีโร่ฝั่งเรา (ล้ม = 0) กลับใน `hooks.done(result, heroes)` → `setHp` เขียนลงเซฟ — ทุกผล (ชนะ แพ้ เสมอ หนี)
- **กติกาอยู่ที่ `ui/vitals.ts`** (`hpShare`, `isDown`, `setHp`, `fitTeam`, `usePotion`, `useRevive`, `wakeFallen`, `downLeft`) — วันหลังย้ายไป `GameService` พร้อมเซฟ; **ตัวเลขอยู่ที่ game-data** `VITALS` (ร่างแรก)
- `WorldScene.startBattle` ไม่เริ่มสู้ถ้าทั้งทีมล้ม
- **แถบทีม** `ui/party.ts` ใน HUD: ตำแหน่งใต้กล่องเควส (Hud.ts `placeChat` วัดแล้ววาง), มือถือแนวตั้งเป็นคอลัมน์ด้านซ้ายใต้แชท; แตะฮีโร่เพื่อใช้ยา
- ไอคอนยาชุบชีวิต `revive.png` = ไอคอนยาฟื้นฟูเปลี่ยนน้ำยาเป็นสีทอง (ไม่ใช้ PixelLab)

## ผลที่ตามมา
- เลือดต่ำ/ล้มมีผลจริง → ยาฟื้นฟู/ยาชุบชีวิตมีค่า; ต้องมีที่ได้ยาเพิ่ม (ร้านค้ามียาฟื้นฟูแล้ว, ยาชุบชีวิตยังไม่มีขาย)
- ทีมที่เหลือน้อยกว่า 5 ตัว (บางตัวล้ม) จัดแถวใหม่ตาม `formation`
- passive/ฮีลหลังสู้ยังไม่มี — ถ้าต้องการฟื้นที่เมือง/โรงเตี๊ยม ต้องเพิ่มทีหลัง
